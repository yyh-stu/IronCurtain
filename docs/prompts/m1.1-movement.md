# M1.1 线单位战场 —— 实体移动系统

## 一、角色与任务
你是《铁幕:前线》Unity 6 项目的战斗系统主程。本模块在现有确定性核心上实现**线单位移动**:3×30 格战场内,单位按"格/秒"沿行列推进、遇占用排队等待。这是后续交战/攻城模块的地基,必须严格确定性(纯 tick 驱动,无 Unity API)。
允许修改:`Entity.cs`、`SimCore.cs`、`SimEvent.cs`(新增枚举值)。禁止修改其他文件。

## 二、GDD 原文摘录
> 2.2 线单位战场空间:单个线空间规格为三排三十格,每格容纳一个英雄身位,单条路线最大承载九十单位。所有英雄移动、交战均在线单位内完成,移速单位为格 / 秒。

## 三、接口契约(严格按此)

### 3.1 SimEvent.cs 新增
`SimEventType` 增加成员:`UnitAdvanced`(单位跨入新格时发,SubjectId=单位 Id)。

### 3.2 Entity.cs 扩展
在现有字段(Id/Side/Kind/Pos/Hp)基础上新增:
- `public HeroId? Hero`(单位=具体英雄,建筑=null;HeroId 已在 Config 命名空间)
- `public BuildingId? Building`(建筑=具体类型,单位=null)
- `public float MoveSpeed`(格/秒;建筑为 0)
- `public EntityState State`(新增 enum,见下;默认 Idle)
- `public bool HasMoveTarget`、`public GridPos MoveTarget`(HasMoveTarget=true 时有效)
- `public float MoveAccum`(跨格进度累计,内部使用)
构造参数保持原有顺序(id, side, kind, pos, hp),新增字段全部用默认值,已有 13 个测试不得破坏。
新增 `public enum EntityState { Idle, Moving, Attacking, Dead }`(放 Sim 命名空间,可同文件)。

### 3.3 SimCore.cs 修改
- 新增 `public void SetMoveTarget(int id, GridPos target)`:
  - 实体不存在或 Kind!=Unit 或 !grid.InBounds(target) → 抛 InvalidOperationException(中文消息)
  - 否则设 MoveTarget/HasMoveTarget=true,State=Moving
- 新增私有 `MoveUnits()`:在 Step() 内命令执行完之后调用。逻辑:
  - 遍历所有 HasMoveTarget 且 State==Moving 且 MoveSpeed>0 的实体
  - 每 tick 移动量 = MoveSpeed / Config.TickRate(累积到 MoveAccum)
  - 当 MoveAccum ≥ 1.0:按**先列后行**原则尝试推进(即:若 Col 与目标 Col 不同则沿 Col 方向跨 1 格;否则若 Row 不同沿 Row 跨 1 格);目标格空(无任何实体占用)才跨入,跨入时更新 Pos、清除原格占用/登记新格占用、MoveAccum-=1.0、发 UnitAdvanced 事件;目标格被占则保持原位不消耗 MoveAccum(排队等待)
  - 到达 MoveTarget(Manhattan 距离 0)或与目标格相邻(距离 1)且目标格被占 → 清 HasMoveTarget、State=Idle
  - 每 tick 最多跨 1 格(剩余 MoveAccum 保留至下 tick)
- Step() 保持:StepBegin → 命令 → **MoveUnits()** → StepEnd
- 占用管理复用现有 `_occupied` HashSet(注意 SpawnEntity/RemoveEntity 已维护,移动时同步维护)

### 3.4 测试新增 `Assets/Tests/EditMode/MovementTests.cs`(EditMode,[Test] 6 个)
1. 匀速推进:实体 MoveSpeed=2,SetMoveTarget(0, 从 Col0 到 Col10),Step 50 次后 Pos.Col==10(2格/s × 5s × 10tick/s;路径全空)
2. 先列后行:实体在 (0,0) MoveSpeed=1,目标 (2,3);Step 5 次内先到 (0,3) 再向 Row 推进,最终 Pos==(2,3)
3. 排队等待:实体 A 停在 (0,5);实体 B 在 (0,4) 目标 (0,9),MoveSpeed=2;Step 100 次后 B 的 Col ≤ 5 且从未与 A 同格(用事件断言 B 最大 Col 到达过 4→5 且不超 5...简化:断言 B 最终 Col==5、State==Idle)
4. 到达即停:目标格空,实体到达后 HasMoveTarget==false、State==Idle、Pos==目标
5. 非法目标:目标越界抛 InvalidOperationException;对建筑(可 spawn Kind=Building 后设 MoveSpeed 无意义)直接对建筑 SetMoveTarget 抛异常
6. 事件流:移动过程 UnitAdvanced 事件数 == 实际跨格数
