# M3.4 摧毁废墟重建 —— 拆塔/废墟/1EP重建/大本营判负/优先级(GL M 绿场实现+测试)

## 一、角色与任务
你是《铁幕:前线》Unity 6 项目攻城收官主程。本模块实现**摧毁-废墟-重建闭环**。只新增两个文件:`Assets/Scripts/Sim/DestroySystem.cs` 与 `Assets/Tests/EditMode/DestroyTests.cs`。**禁止修改任何既有文件**(83 个既有测试必须保持全绿)。编排者已挂好钩子:Step 末尾已调用 `DestroySystem.Tick(this, dt)`,Entity 已有 `Rubbled`/`IsCharging`/`ChargeHitUsed` 字段,SimCore 已有 `Winner`/`SetWinner`/`SpendEp`/`EpOf`,GarrisonSystem 已有 `OnBuildingRubbled(sim, b)`(废墟时全部驻军后撤)。

## 二、规则(权威,GDD + 拍板)
- GDD 2.5.2 拆塔每秒伤害:普通近战(磐石/断峰)2 / 镇岳 4 / 射手(坠日/星落)4 / 逐风 3。
- 用户拍板(冲锋拆塔):任何情况下逐风拆塔 3/s;**冲锋状态攻击建筑的第一击为 5**(一次性),后续依旧 3/s;攻击间隔与普攻一致;飞掠是冲锋升级版(第一击 7)——飞掠属 M4.1,本模块只实现"冲锋首击 5"。
- GDD 2.5.2 废墟:建筑血量清空 → 城内守军全部清除、建筑变废墟;废墟需消耗 1EP 重建;**用户拍板:重建后归属重建者**,满血恢复。
- GDD 2.5.2:中立建筑无血量,远程攻击无法造成伤害(本模块:中立非废墟建筑完全不受拆塔伤害)。
- GDD 2.5.3:大本营血量清零直接判负(本模块:SimCore.SetWinner(进攻方))。
- D26(拍板):攻击优先级——拆塔单位射程内若有敌军单位,先接战单位(战斗主循环已处理),只有无单位可打时才攻击建筑。
- D22(拍板):封城中意图锁死——封城中无法下达摧毁意图(意图层已拦,本模块无需处理)。

## 四、接口契约(严格实现)

### DestroySystem.cs(`namespace IronCurtain.Sim`,静态类)
```csharp
public static void Tick(SimCore sim, float dt);
// 遍历所有"持有摧毁意图"的单位(TargetBuildingId!=0):
//   目标建筑 = GetEntity(TargetBuildingId);无效/已 Rubbled/已不在 → 清 TargetBuildingId,State=Idle(原地待命)
//   意图校验:建筑 Intent==Destroy 且 IntentIssuer==单位.Side 才拆(否则跳过该单位)
//   中立非废墟建筑(Side==Neutral) → 不受伤,跳过
//   距离校验:IsRanged(单位) → 曼哈顿≤单位.Range;近战 → 曼哈顿≤1
//   优先级(D26):射程内存在敌军单位 → 本 tick 不拆塔(战斗主循环会处理接战);无 → 进入攻击循环:
//     冷却共享 e.AttackCooldown;当 ≤0 时:
//       伤害 = 每秒速率 × AttackIntervalSec(速率按英雄取 Siege 配置;Hero==null 的单位取 MeleePerSec)
//       逐风(Hero==ZhuFeng)且 IsCharging 且 !ChargeHitUsed → 本次伤害 = ZhuFengChargeHit(5),置 ChargeHitUsed=true
//       建筑 Hp -= 伤害;若 Hp ≤ 0:
//          Building==Base → sim.SetWinner(单位.Side);Hp 归 0,不再进入废墟流程
//          否则 → Rubbled=true;Side=Neutral;Hp=0;GarrisonSystem.OnBuildingRubbled(sim, b);
//                  清 Intent/IntentIssuer/Sealed;所有以该建筑为 TargetBuildingId 的单位清目标并 Idle
//       攻击后 e.AttackCooldown = AttackIntervalSec
//   逐风 !IsCharging 时 ChargeHitUsed=false(重置)
public static bool Rebuild(SimCore sim, int buildingId, Side side, out string error);
// 建筑存在且 Rubbled → 校验 sim.SpendEp(side, 1):失败 → error="EP 不足",返回 false
// 成功 → Rubbled=false;Side=side;Hp=MaxHp(用 sim.BuildingConfigOf 重新取);返回 true
// 建筑非废墟 → error="非废墟"
```

### DestroyTests.cs(EditMode,[Test] 10 个)
SetUp 照抄既有模式;蓝塔 (1,6)、红塔 (1,22)、中立资源点 (1,14)、蓝大本营 (1,0)。
1. 磐石近战拆塔节奏:红磐石邻接蓝塔(1,5),意图 Destroy → 20 tick(1 击)后蓝塔 Hp=50-4(2×2s)
2. 镇岳拆塔:邻接 → 1 击 8(4×2)
3. 射手远程拆塔:红坠日 (1,10)(距蓝塔 4≤射程5)→ 1 击 8(4×2)
4. 逐风冲锋首击:红逐风邻接蓝塔,IsCharging=true → 首击 5,次击(再 20 tick)6;ChargeHitUsed 置位;取消冲锋(IsCharging=false)后 ChargeHitUsed 复位
5. 优先级 D26:红磐石拆蓝塔,蓝断峰放在 (1,5) 邻接 → 20 tick 内蓝塔 Hp 不变、蓝断峰掉血
6. 废墟化+守军后撤:蓝塔驻军 2(EnterFormal),红坠日远程拆至 0 → Rubbled==true、Side==Neutral、驻军离城且 State==Routing
7. 中立不可摧毁:中立资源点 (1,14) 设意图?中立不可设 Destroy(SetIntent 会拒)——改为:直接让单位 TargetBuildingId=中立点并 Intent 绕过?不可。**改为断言 SetIntent 被拒**(error 含"中立")——与 M3.1 重复但属本模块闭环;再补:红坠日对无归属中立资源点攻击 → 无伤害(资源点 Hp 恒 0 且不死)
8. 废墟意图锁:蓝塔设为 Rubbled → SetIntent(…,Destroy/Capture) 返回 false,error 含"重建"
9. 重建归重建者:蓝塔 Rubbled;红方 EP 满 5 → Rebuild(红) → Side==Red、Hp==MaxHp、Rubbled==false;再试 Rebuild 蓝方(EP 0)→ error 含"EP"
10. 大本营判负:蓝大本营 (1,0),红镇岳邻接拆 → Hp 归 0 后 sim.Winner==Side.Red
