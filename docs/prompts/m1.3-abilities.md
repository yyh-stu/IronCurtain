## 二、已有 API(直接使用,勿改)
```csharp
namespace IronCurtain.Sim {
  public enum DebuffType { Slow, Silence, Wound, Fragile }
  public sealed class StatusEffects {
    bool Has(DebuffType t);
    void Apply(DebuffType t, float seconds);   // 仅新时长>剩余时刷新
    void Tick(float dt);
    float MoveMultiplier;            // Slow→0.7, Wound→0.85
    float AttackIntervalMultiplier;  // Slow→1.1
    float AttackMultiplier;          // Wound→0.85
    float DamageTakenMultiplier;     // Wound→1.15, Fragile→1.1,可叠乘
  }
  public static class HeroAbilitySystem {
    const float SilenceSeconds = 2f;       // 星落沉默 2s
    const float PanShiRegenPerSec = 20f;   // 磐石脱战回盾 20/s
    const float PanShiRegenDelay = 5f;     // 脱战 5s 起
    const float PanShiChargeBlockRange = 1;   // 磐石禁冲范围 1 格
    const float DuanFengChargeBreakRange = 2; // 断峰拒马范围 2 格
    static void ApplyOnHitEffects(Entity attacker, Entity defender); // 星落→沉默(非镇岳) 2s;断峰→迟滞 3s;坠日→镇岳重伤 3s
    static void UpdatePanShiShield(Entity e, float dt);              // 脱战满5s后 20/s 回盾
    static bool CanCharge(Entity zf, SimCore sim);                   // 沉默中/附近1格有敌磐石/2格有敌断峰 → false
  }
}
```
Entity 关键字段:Id/Side/Kind/Pos/Hp/MaxHp/Attack/AttackIntervalSec/AttackCooldown/Range/Shield/ShieldMax/MoveSpeed/IsCharging/State/Hero(可空)/Status(StatusEffects)/SecondsSinceCombat。
SimCore 关键 API:SpawnEntity(Side, EntityKind, GridPos)→Entity;SetMoveTarget(id,pos);SubmitCommand(ICommand);Step();Tick;AddEventListener(Action<SimEvent>);GetEntity(id);RemoveEntity(id);Game(GameConfig);Entities(IReadOnlyDictionary<int,Entity>);EntityCount。
SimEvent:Type(enum 含 DamageDealt/EntityDied/UnitAdvanced...)/Tick/SubjectId/Amount。
引擎每 tick 自动执行:状态 Tick、脱战计时、磐石回盾、逐风冲锋约束检查(被拒马/禁冲/沉默时 IsCharging 自动=false)、索敌攻击(攻击间隔内出手一次)、命中后 ApplyOnHitEffects。
伤害结算顺序:基础伤害(公式) × 攻击方 AttackMultiplier × 防守方 DamageTakenMultiplier → 先扣盾后扣血。
配置加载(照抄 CombatTests 模式):`Resources.Load<TextAsset>("gameconfig")` → `GameConfigParser.FromJson(ta.text)`;英雄属性从 cfg.Heroes 按 Id 取(注意 double 字段赋给 float 要 (float) 转换)。
生成英雄单位示例(可直接复制):
```csharp
var c = Hero(id); var e = sim.SpawnEntity(side, EntityKind.Unit, pos);
e.Hero = id; e.MaxHp = c.MaxHp; e.Hp = c.MaxHp; e.Attack = c.Attack;
e.AttackIntervalSec = (float)c.AttackIntervalSec; e.Range = c.Range; e.MoveSpeed = (float)c.MoveSpeed;
if (c.Shield > 0) { e.Shield = c.Shield; e.ShieldMax = c.Shield; }
```

## 三、要写的测试(文件 `Assets/Tests/EditMode/HeroAbilityTests.cs`,EditMode,[Test] 8 个)
1. **磐石脱战回盾**:磐石被打一下(护盾-35),5 秒内不回盾;脱战满 5 秒后开始每秒 +20,直到回满 140 不再涨。
2. **磐石禁冲锋**:逐风旁边 1 格放敌磐石 → 逐风 IsCharging=true 后 Step → 自动变 false。
3. **断峰拒马**:逐风 IsCharging=true,2 格内放敌断峰 → Step 后 IsCharging=false;断峰 3 格外时不受影响。
4. **星落沉默**:星落攻击逐风 → 逐风 Status.Has(Silence)==true;持续约 2 秒后消失(攻击间隔 1s,注意时序:沉默 2s=20tick,在第 1 次命中后 20 tick 内有效,21 tick 后失效);且沉默期间 IsCharging=true 会被自动清除。
5. **星落不沉默镇岳**:星落攻击镇岳 → 镇岳无 Silence。
6. **断峰迟滞**:断峰攻击任意单位 → 目标 Status.Has(Slow)==true;被迟滞单位 MoveMultiplier==0.7、AttackIntervalMultiplier==1.1;3 秒后消失(30 tick)。
7. **坠日重伤**:坠日攻击镇岳 → 镇岳 Status.Has(Wound)==true;镇岳反击伤害 ×0.85(实测:镇岳打坠日原本 14,重伤后 14×0.85=11.9;断言用实际伤害事件 Amount 或直接算 hp 差);3 秒后消失。
8. **迟滞实际拖慢攻速**:被断峰迟滞的目标,两次攻击间隔变长(攻击间隔 2s → ×1.1 = 2.2s = 22 tick):在 20 tick 处第二次出手尚未发生,22 tick 后已发生(用 DamageDealt 事件计数断言)。
