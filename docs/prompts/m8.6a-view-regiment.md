# M8.6a 将兵化改造·View 兵团渲染(第一批:士兵占位模型 + 兵力标签)

## 一、角色与任务
你是《铁幕:前线》Unity 6(URP 17)表现层主程。将兵制 Sim 已落地(兵团=1 主将+20 兵,Entity.IsSoldier/GeneralId/FormationSlot)。本轮 View 第一批:
- **士兵占位渲染**:士兵(IsSoldier)不再渲染成完整英雄模型,改用轻量程序化占位人形(矮小、阵营色),正式士兵美术由 AI 管线后续替换(此处留统一入口);
- **主将兵力标签**:主将(非士兵单位)头顶显示"兵力 X/20"文字标签。
**只允许输出/修改以下 2 个文件,其余零改动:**
- `Assets/Scripts/View/EntityView.cs`
- `Assets/Scripts/View/BoardView.cs`(只改 CreateView 传参一处)

## 二、需求与规范(权威)
### 2.1 士兵占位渲染(EntityView)
- `Bind` 中:若 `e.IsSoldier` → 走 `BuildSoldier()`(占位),**不建血条**(BuildHpBar 跳过)、不建光环盘、不建旗帜;否则走现有 BuildUnit/BuildBuilding 逻辑(逐字保留)。
- `BuildSoldier()`:程序化小体:躯干(AddBox 0.36×0.5×0.24,中心 y=0.35)+头(AddBox 0.22 立方,中心 y=0.72)+武器棒(AddBox 0.05×0.06×0.7,中心 y=0.5,z=+0.24,朝 +z 或按阵营朝 ±x 均可),总高 ≈0.85m(比主将矮,不喧宾夺主);材质=阵营哑光色(蓝 `Flat(Color(0.25,0.42,0.72))`、红 `Flat(Color(0.72,0.30,0.26))`、中立 `Flat(Color(0.55,0.55,0.52))`,smoothness 0.3);模型根命名 "SoldierModel" 挂在 `_model` 下(用 ViewAssets.DecoBox 或合并网格均可,单文件 ≤350 行)。
- 朝向:士兵 yaw 随主将阵营(蓝 +90°/红 -90°,与现有单位一致)在 Tick 中保持(现有单位朝向逻辑不动,士兵同款即可)。
- `Tick` 中士兵:照常跟随位置(现有 BoardView.WorldPos(e.PosF) 路径已覆盖);`SetHp` 对士兵无血条时直接 return(已有 _hpFill null 守卫,确认即可);死亡缩隐/驻军隐藏(正式驻军 GarrisonBuildingId!=0 隐藏模型)沿用现有逻辑。
- **正式士兵美术替换入口**:新增 `private static bool UseSoldierArtPlaceholder = true;` 常量+注释"AI 管线士兵模型接入后改为加载 Resources 模型"。

### 2.2 主将兵力标签(EntityView + BoardView)
- EntityView 新增:
  - `private TextMesh _countLabel; private float _countRefresh; private System.Func<int> _soldierCountOf;`
  - `Bind` 增加可选参数 `System.Func<int> soldierCountOf = null`;若 `e.Kind==Unit && !e.IsSoldier`(主将)且 delegate 非空 → `BuildCountLabel()`:子 GameObject("CountLabel") 挂 `TextMesh`,text "20/20",`font=ViewAssets.UiFont(14)`,fontSize 36、`characterSize=0.14f`、`fontStyle=FontStyle.Bold`、color=阵营亮色(ViewAssets.TeamColor(side)),localPosition=(0, 3.2f, 0),`anchor=TextAnchor.MiddleCenter`;`renderer.sharedMaterial = ViewAssets.Flat(Color.white)`(TextMesh 需要字体材质,若渲染异常用内置 Font 材质处理)。
  - `Tick` 中:`_countRefresh += dt;` 每 0.5s 刷新一次 label 文本 = $"{_soldierCountOf()}/{RegimentSystem.SoldiersPerGeneral}"。
  - 士兵/建筑不建该标签。
- BoardView `CreateView`:`view.Bind(e, e.Side, e.Hero, e.Building, e.Kind == EntityKind.Unit && !e.IsSoldier ? (System.Func<int>)(() => { int c = 0; foreach (var x in _sim.Entities.Values) if (x.IsSoldier && x.GeneralId == e.Id && x.State != EntityState.Dead) c++; return c; }) : null);`
  (closure 捕获 e 时注意 foreach 变量:用局部 `var ent = e;` 再闭包,避免捕获迭代变量。)
- 标签随单位移动(挂 EntityView 根下)、随死亡隐藏(SetDead 缩隐时同时 `_countLabel` 随 transform 缩放,自然生效)。

### 2.3 通用约束
- 单文件 ≤350 行;命名空间 `IronCurtain.View`;只读 Sim;URP/Lit 材质(经 ViewAssets);不用 TextMeshPro;不引入新资产/包。

### 3.1 EntityView.cs
```csharp
using System.Collections.Generic;
using IronCurtain.Sim;
using UnityEngine;

namespace IronCurtain.View
{
    public sealed class EntityView : MonoBehaviour
    {
        private Entity _e;
        private Side _side;
        private GameObject _model, _gr, _chunks;
        private Transform _hpRoot, _hpFill, _shFill;
        private float _w = 1.7f, _h = 0.26f, _deadT = -1f, _topY = 3.5f;
        private bool _dead, _rubbled;
        private int _gf = -1, _gt = -1;
        private Material _g, _y, _r, _bk, _sh, _rubG, _gA, _gB;

        public void Bind(Entity e, Side side, HeroId? hero, BuildingId? building)
        {
            _e = e; _side = side;
            InitMats();
            if (e.Kind == EntityKind.Unit) BuildUnit(hero.HasValue ? hero.Value : HeroId.PanShi);
            else BuildBuilding(building.HasValue ? building.Value : BuildingId.Tower);
            BuildHpBar();
            transform.position = e.Kind == EntityKind.Building ? BoardView.WorldPos(e.Pos) : BoardView.WorldPos(e.PosF);
            if (e.Kind == EntityKind.Unit)
                transform.rotation = Quaternion.Euler(0f, side == Side.Blue ? 90f : -90f, 0f);
        }

        private void InitMats()
        {
            if (_g != null) return;
            _bk = ViewAssets.Flat(new Color(0.18f, 0.18f, 0.20f));
            _g = ViewAssets.Mat(Color.green, 0f, 0.4f, Color.green, 0.8f);
            _y = ViewAssets.Mat(new Color(1f, 0.85f, 0f), 0f, 0.4f, new Color(1f, 0.85f, 0f), 0.8f);
            _r = ViewAssets.Mat(Color.red, 0f, 0.4f, Color.red, 0.8f);
            _sh = ViewAssets.Mat(new Color(0.4f, 0.8f, 1f), 0f, 0.4f, new Color(0.4f, 0.8f, 1f), 1.2f);
            _rubG = ViewAssets.Flat(new Color(0.15f, 0.14f, 0.13f));
            _gA = ViewAssets.Mat(Color.black, 0f, 0.9f, new Color(1f, 1f, 0.9f), 2.2f);
            _gB = ViewAssets.Mat(Color.black, 0f, 0.9f, new Color(0.4f, 0.4f, 0.4f), 0.7f);
        }

        public void FlashHit() { }

        public void SetDead()
        {
            if (_dead) return;
            _dead = true; _deadT = 0f;
        }

        public void SetHp(float hp, float maxHp)
        {
            if (_hpFill == null) return;
            float t = maxHp > 0f ? Mathf.Clamp01(hp / maxHp) : 0f;
            bool show = _e.Kind == EntityKind.Building || t < 0.999f;
            _hpRoot.gameObject.SetActive(show);
            _hpFill.localScale = new Vector3(_w * t, _h, 1f);
            _hpFill.localPosition = new Vector3(-_w * (1f - t) * 0.5f, 0f, 0f);
            _hpFill.GetComponent<MeshRenderer>().sharedMaterial = t > 0.5f ? _g : (t > 0.25f ? _y : _r);
        }

        public void TickBillboard(Camera cam)
        {
            if (_hpRoot != null && cam != null)
                _hpRoot.rotation = Quaternion.LookRotation(_hpRoot.position - cam.transform.position);
        }

        public void Tick(float dt, Camera cam)
        {
            if (_e == null) return;
            bool isB = _e.Kind == EntityKind.Building;
            bool hidden = !isB && _e.GarrisonBuildingId != 0;
            bool vis = !hidden && !_rubbled;
            if (_model != null && _model.activeSelf != vis) { _model.SetActive(vis); _hpRoot.gameObject.SetActive(!hidden); }
            if (!hidden)
            {
                Vector3 target = isB ? BoardView.WorldPos(_e.Pos) : BoardView.WorldPos(_e.PosF);
                if (isB) transform.position = target;
                else transform.position = Vector3.Lerp(transform.position, target, 1f - Mathf.Exp(-14f * dt));
                SetHp(_e.Hp, _e.MaxHp);
            }
            if (_e.Rubbled && !_rubbled) SetRubbled(true);
            if (!_e.Rubbled && _rubbled) SetRubbled(false);
            if (isB) UpdateGarrison();
            UpdateShield();
            TickBillboard(cam);
            if (_dead)
            {
                _deadT += dt;
                float s = Mathf.Max(0.01f, 1f - _deadT * 4f);
                transform.localScale = Vector3.one * s;
            }
            else transform.localScale = Vector3.one;
        }

        private void UpdateGarrison()
        {
            int f = _e.GarrisonFormal.Count, t = _e.GarrisonTemp.Count;
            if (f == t && f == _gf && t == _gt) return;
            _gf = f; _gt = t;
            if (_gr != null) Destroy(_gr);
            _gr = null;
            if (f + t == 0) return;
            _gr = new GameObject("Garrison");
            _gr.transform.SetParent(transform, false);
            int n = f + t;
            for (int i = 0; i < n; i++)
            {
                float a = i / (float)Mathf.Max(1, n) * Mathf.PI * 2f;
                ViewAssets.DecoBox(i < f ? _gA : _gB,
                    new Vector3(Mathf.Cos(a) * 2.3f, _topY, Mathf.Sin(a) * 2.3f),
                    Vector3.one * 0.4f, _gr.transform, "d" + i);
            }
        }

        private void UpdateShield()
        {
            if (_shFill == null) return;
            bool show = _e.Shield > 0.01f && _e.ShieldMax > 0.01f;
            _shFill.gameObject.SetActive(show);
            if (show)
            {
                float t = Mathf.Clamp01(_e.Shield / _e.ShieldMax);
                _shFill.localScale = new Vector3(_w * t, 0.05f, 1f);
                _shFill.localPosition = new Vector3(-_w * (1f - t) * 0.5f, 0.14f, 0f);
            }
        }

        private void BuildHpBar()
        {
            var root = new GameObject("HpBar");
            root.transform.SetParent(transform, false);
            root.transform.localPosition = new Vector3(0f, _e.Kind == EntityKind.Building ? _topY + 0.9f : 2.7f, 0f);
            _hpRoot = root.transform;
            ViewAssets.DecoQuad(_bk, Vector3.zero, new Vector2(_w, _h), root.transform, "Back");
            _hpFill = ViewAssets.DecoQuad(_g, Vector3.zero, new Vector2(_w, _h), root.transform, "Fill").transform;
            _shFill = ViewAssets.DecoQuad(_sh, new Vector3(0f, 0.14f, 0f), new Vector2(_w, 0.05f), root.transform, "Shield").transform;
            _shFill.gameObject.SetActive(false);
        }

        // ===== Kenney 模型加载与组合 =====

        private GameObject NewModelRoot()
        {
            var go = new GameObject("Model");
            go.transform.SetParent(transform, false);
            return go;
        }

        private float PieceHeight(GameObject go)
        {
            bool found = false; var b = new Bounds();
            foreach (var rr in go.GetComponentsInChildren<Renderer>())
            {
                if (!found) { b = rr.bounds; found = true; }
                else b.Encapsulate(rr.bounds);
            }
            return found ? b.size.y : 0f;
        }

        private GameObject AddPiece(Transform parent, string name, float targetH, float y)
        {
            var prefab = Resources.Load<GameObject>("Models/" + name);
            if (prefab == null) { Debug.LogWarning("[EntityView] Missing model: " + name); return null; }
            var go = Instantiate(prefab, parent);
            go.name = name;
            float ph = PieceHeight(go);
            float s = ph > 0.0001f ? targetH / ph : 1f;
            go.transform.localScale = Vector3.one * s;
            go.transform.localPosition = new Vector3(0f, y + targetH * 0.5f, 0f);
            go.transform.localRotation = Quaternion.identity;
            return go;
        }

        private Color TeamGlowColor()
        {
            if (_side == Side.Blue) return new Color(0.4f, 0.8f, 1f);
            if (_side == Side.Red) return new Color(1f, 0.4f, 0.35f);
            return new Color(0.35f, 1f, 0.55f);
        }

        private void AddGlowDisc(Transform parent, float radius)
        {
            Material glow = ViewAssets.Mat(TeamGlowColor() * 0.32f, 0f, 0.7f, TeamGlowColor(), 0.55f);
            ViewAssets.DecoBox(glow, new Vector3(0f, 0.02f, 0f), new Vector3(radius * 2f, 0.025f, radius * 2f), parent, "GlowDisc");
        }

        private void AddFlag(Transform parent, Vector3 pos, float height)
        {
            Color fc = _side == Side.Blue ? new Color(0.2f, 0.85f, 1f)
                : (_side == Side.Red ? new Color(1f, 0.3f, 0.25f) : new Color(0.5f, 0.75f, 0.5f));
            Material pm = ViewAssets.Flat(new Color(0.25f, 0.22f, 0.18f));
            Material fm = ViewAssets.Flat(fc);
            ViewAssets.DecoBox(pm, pos + new Vector3(0f, height * 0.5f, 0f), new Vector3(0.08f, height, 0.08f), parent, "FlagPole");
            ViewAssets.DecoBox(fm, pos + new Vector3(0.5f, height - 0.34f, 0f), new Vector3(0.9f, 0.55f, 0.06f), parent, "Flag");
        }

        private void TintRenderers(GameObject go, Color tint)
        {
            foreach (var rr in go.GetComponentsInChildren<Renderer>())
            {
                var mats = rr.sharedMaterials;
                for (int i = 0; i < mats.Length; i++)
                {
                    if (mats[i] == null) continue;
                    var m = Instantiate(mats[i]);
                    if (m.HasProperty("_BaseColor")) m.SetColor("_BaseColor", m.GetColor("_BaseColor") * tint);
                    else m.color = m.color * tint;
                    mats[i] = m;
                }
                rr.sharedMaterials = mats;
            }
        }

        private void GreyRenderers(GameObject go)
        {
            foreach (var rr in go.GetComponentsInChildren<Renderer>())
            {
                var mats = rr.sharedMaterials;
                for (int i = 0; i < mats.Length; i++)
                    if (mats[i] != null) mats[i] = Instantiate(ViewAssets.Flat(new Color(0.62f, 0.62f, 0.60f)));
                rr.sharedMaterials = mats;
            }
        }

        // ===== 单位:英雄 → Kenney 角色映射(后续替换机甲模型只改此处)=====

        private static string HeroModelName(HeroId hero)
        {
            switch (hero)
            {
                case HeroId.PanShi: return "character-a";
                case HeroId.ZhenYue: return "character-b";
                case HeroId.DuanFeng: return "character-c";
                case HeroId.ZhuFeng: return "character-d";
                case HeroId.ZhuiRi: return "character-e";
                case HeroId.XingLuo:
                default: return "character-f";
            }
        }

        private void BuildUnit(HeroId hero)
        {
            _model = NewModelRoot();
            var body = AddPiece(_model.transform, HeroModelName(hero), 2.4f, 0f);
            if (body != null)
                TintRenderers(body, _side == Side.Blue ? new Color(0.6f, 0.8f, 1f)
                    : (_side == Side.Red ? new Color(1f, 0.6f, 0.55f) : Color.white));
            AddGlowDisc(_model.transform, 1.15f);
        }

        private void BuildBuilding(BuildingId type)
        {
            _model = NewModelRoot();
            bool neutral = _side == Side.Neutral;
            bool fort = _e.IsFort && type == BuildingId.ResourcePoint;
            switch (type)
            {
                case BuildingId.Base:
                    AddPiece(_model.transform, "tower-square-base", 3.6f, 0f);
                    AddPiece(_model.transform, "tower-square-mid", 4.2f, 3.6f);
                    AddPiece(_model.transform, "tower-square-top-roof", 3.6f, 7.8f);
                    _topY = 11.4f; AddGlowDisc(_model.transform, 7.2f);
                    break;
                case BuildingId.Barracks:
                    AddPiece(_model.transform, "tower-square-mid-door", 4.4f, 0f);
                    AddPiece(_model.transform, "tower-square-roof", 1.8f, 4.4f);
                    _topY = 6.2f; AddGlowDisc(_model.transform, 5.0f);
                    AddFlag(_model.transform, new Vector3(3.6f, 0f, 3.6f), 3.6f);
                    break;
                case BuildingId.ResourcePoint:
                    if (fort)
                    {
                        var stall = AddPiece(_model.transform, "stall", 4.0f, 0f);
                        _topY = 4.4f;
                        Material gm = ViewAssets.Mat(Color.black, 0f, 0.9f, TeamGlowColor(), 2.2f);
                        for (int i = 0; i < 3; i++)
                        {
                            float a = i * Mathf.PI * 2f / 3f;
                            ViewAssets.DecoBox(gm, new Vector3(Mathf.Cos(a) * 1.7f, 4.7f, Mathf.Sin(a) * 1.7f),
                                Vector3.one * 0.5f, _model.transform, "fortglow" + i);
                        }
                        if (stall != null && neutral) GreyRenderers(stall);
                    }
                    else
                    {
                        AddPiece(_model.transform, neutral ? "watermill" : "windmill", 7.0f, 0f);
                        _topY = 7.0f;
                    }
                    AddGlowDisc(_model.transform, 4.4f);
                    break;
                case BuildingId.Tower:
                default:
                    AddPiece(_model.transform, "tower-hexagon-base", 2.6f, 0f);
                    AddPiece(_model.transform, "tower-hexagon-mid", 4.0f, 2.6f);
                    AddPiece(_model.transform, "tower-hexagon-roof", 2.0f, 6.6f);
                    _topY = 8.6f; AddGlowDisc(_model.transform, 5.6f);
                    break;
            }
            if (!fort) AddFlag(_model.transform, new Vector3(6.0f, 0f, type == BuildingId.Barracks ? -1.8f : 0f), 5.0f);
            if (neutral && type != BuildingId.ResourcePoint) GreyRenderers(_model);
            else if (!neutral)
                TintRenderers(_model, _side == Side.Blue ? new Color(0.55f, 0.72f, 1f) : new Color(1f, 0.55f, 0.45f)); // 建筑阵营 tint(红方暖、蓝方冷)
        }

        public void SetRubbled(bool on)
        {
            if (_rubbled == on || _model == null) return;
            _rubbled = on;
            if (_chunks != null) { Destroy(_chunks); _chunks = null; }
            _model.SetActive(!on);
            if (!on) return;
            _chunks = new GameObject("Rubble");
            _chunks.transform.SetParent(transform, false);
            string main = _e.Building == BuildingId.ResourcePoint ? "cart" : "siege-tower-demolished";
            var go = AddPiece(_chunks.transform, main, 4.0f, 0f);
            if (go != null) go.transform.localScale *= 0.9f;
            for (int i = 0; i < 3; i++)
            {
                float a = i * 2.1f + 0.7f;
                var rk = AddPiece(_chunks.transform, "rocks-small", 0.7f, 0f);
                if (rk != null) rk.transform.localPosition = new Vector3(Mathf.Cos(a) * 2.6f, 0.2f, Mathf.Sin(a) * 2.6f);
            }
            if (_chunks.transform.childCount == 0) { Destroy(_chunks); _chunks = null; }
        }
    }
}
```

```csharp
using System.Collections.Generic;
using IronCurtain.Sim;
using UnityEngine;

namespace IronCurtain.View
{
    public sealed class BoardView : MonoBehaviour
    {
        private SimCore _sim;
        private readonly Dictionary<int, EntityView> _views = new Dictionary<int, EntityView>();

        public static Vector3 WorldPos(SimVec2 p) { return new Vector3(p.X, 0f, 3f - p.Y); }
        public static Vector3 WorldPos(GridPos p) { return new Vector3(p.Col, 0f, 3f - p.Row); }

        public void Init(SimCore sim, Transform parent)
        {
            _sim = sim;
            BuildBoard();
            foreach (var kv in sim.Entities)
            {
                var e = kv.Value;
                if (e != null) CreateView(e);
            }
        }

        public EntityView GetView(int entityId)
        {
            EntityView v;
            return _views.TryGetValue(entityId, out v) ? v : null;
        }

        public void OnSimEvent(SimEvent ev)
        {
            switch (ev.Type)
            {
                case SimEventType.EntitySpawned:
                    var e = _sim.GetEntity(ev.SubjectId);
                    if (e != null) CreateView(e);
                    break;
                case SimEventType.EntityRemoved:
                    EntityView rv;
                    if (_views.TryGetValue(ev.SubjectId, out rv))
                    {
                        _views.Remove(ev.SubjectId);
                        if (rv != null && rv.gameObject != null) Destroy(rv.gameObject);
                    }
                    break;
                case SimEventType.DamageDealt:
                    var dv = GetView(ev.SubjectId);
                    if (dv != null) dv.FlashHit();
                    break;
                case SimEventType.EntityDied:
                    var dv2 = GetView(ev.SubjectId);
                    if (dv2 != null) dv2.SetDead();
                    break;
            }
        }

        public void TickViews()
        {
            Camera cam = Camera.main;
            float dt = Time.deltaTime;
            foreach (var kv in _views)
            {
                var v = kv.Value;
                if (v == null) continue;
                var e = _sim.GetEntity(kv.Key);
                if (e == null || e.State == EntityState.Dead) v.SetDead();
                v.Tick(dt, cam);
            }
        }

        private void CreateView(Entity e)
        {
            if (_views.ContainsKey(e.Id)) return;
            var go = new GameObject("Entity_" + e.Id);
            go.transform.SetParent(transform, false);
            var view = go.AddComponent<EntityView>();
            view.Bind(e, e.Side, e.Hero, e.Building);
            _views[e.Id] = view;
        }

        private void BuildBoard()
        {
            TerrainView.Build(transform);
        }
    }
}
```

### 3.3 ViewAssets.cs(只读参考)
```csharp
using System.Collections.Generic;
using IronCurtain.Sim;
using UnityEngine;

namespace IronCurtain.View
{
    public static class ViewAssets
    {
        private static Font _font;
        private static Mesh _quadMesh;

        public static Material Mat(Color albedo, float metallic, float smoothness, Color emission, float emissionIntensity)
        {
            var m = new Material(Shader.Find("Universal Render Pipeline/Lit"));
            m.SetColor("_BaseColor", albedo);
            m.SetFloat("_Metallic", metallic);
            m.SetFloat("_Smoothness", smoothness);
            if (emissionIntensity > 0f)
            {
                m.EnableKeyword("_EMISSION");
                m.SetColor("_EmissionColor", emission * emissionIntensity);
            }
            return m;
        }

        public static Material Flat(Color albedo, float smoothness = 0.4f)
        {
            return Mat(albedo, 0f, smoothness, Color.black, 0f);
        }

        public static Material TeamMat(Side side)
        {
            switch (side)
            {
                case Side.Blue: return Mat(new Color(0.15f, 0.20f, 0.28f), 0.55f, 0.6f, new Color(0.2f, 0.85f, 1f), 1.2f);
                case Side.Red: return Mat(new Color(0.28f, 0.15f, 0.15f), 0.55f, 0.6f, new Color(1f, 0.3f, 0.3f), 1.2f);
                default: return Mat(new Color(0.3f, 0.3f, 0.3f), 0.55f, 0.6f, new Color(0.85f, 0.85f, 0.85f), 0.8f);
            }
        }

        // ---------- 自建网格构建 ----------
        private static void Quad(List<Vector3> v, List<int> t, Vector3 a, Vector3 b, Vector3 c, Vector3 d)
        {
            int i = v.Count;
            v.Add(a); v.Add(b); v.Add(c); v.Add(d);
            t.Add(i); t.Add(i + 1); t.Add(i + 2);
            t.Add(i); t.Add(i + 2); t.Add(i + 3);
        }

        public static void AddBox(List<Vector3> v, List<int> t, Vector3 c, Vector3 s)
        {
            float x = s.x * 0.5f, y = s.y * 0.5f, z = s.z * 0.5f;
            Quad(v, t, c + new Vector3(-x, -y, z), c + new Vector3(x, -y, z), c + new Vector3(x, y, z), c + new Vector3(-x, y, z));
            Quad(v, t, c + new Vector3(x, -y, -z), c + new Vector3(-x, -y, -z), c + new Vector3(-x, y, -z), c + new Vector3(x, y, -z));
            Quad(v, t, c + new Vector3(x, -y, z), c + new Vector3(x, -y, -z), c + new Vector3(x, y, -z), c + new Vector3(x, y, z));
            Quad(v, t, c + new Vector3(-x, -y, -z), c + new Vector3(-x, -y, z), c + new Vector3(-x, y, z), c + new Vector3(-x, y, -z));
            Quad(v, t, c + new Vector3(-x, y, z), c + new Vector3(x, y, z), c + new Vector3(x, y, -z), c + new Vector3(-x, y, -z));
        }

        // 底面中心 c,向上 h;botHalf/topHalf 为 x/z 半宽;seg 边数;angOff 起始角偏移
        public static void AddPrism(List<Vector3> v, List<int> t, Vector3 c, Vector2 botHalf, Vector2 topHalf, float h, int seg, float angOff = 0f)
        {
            float step = Mathf.PI * 2f / seg;
            for (int i = 0; i < seg; i++)
            {
                float a0 = angOff + step * i, a1 = angOff + step * (i + 1);
                var b0 = new Vector3(c.x + Mathf.Cos(a0) * botHalf.x, c.y, c.z + Mathf.Sin(a0) * botHalf.y);
                var b1 = new Vector3(c.x + Mathf.Cos(a1) * botHalf.x, c.y, c.z + Mathf.Sin(a1) * botHalf.y);
                var t0 = new Vector3(c.x + Mathf.Cos(a0) * topHalf.x, c.y + h, c.z + Mathf.Sin(a0) * topHalf.y);
                var t1 = new Vector3(c.x + Mathf.Cos(a1) * topHalf.x, c.y + h, c.z + Mathf.Sin(a1) * topHalf.y);
                Quad(v, t, b0, b1, t1, t0);
                int tc = v.Count;
                v.Add(new Vector3(c.x, c.y + h, c.z));
                t.Add(tc); t.Add(tc + 1); t.Add(tc + 2);
                v.Add(t0); v.Add(t1);
                t.Add(tc); t.Add(tc + 3); t.Add(tc + 4);
                int bc = v.Count;
                v.Add(new Vector3(c.x, c.y, c.z));
                t.Add(bc); t.Add(bc + 2); t.Add(bc + 1);
                v.Add(b0); v.Add(b1);
                t.Add(bc); t.Add(bc + 4); t.Add(bc + 3);
            }
        }

        public static void AddCylinder(List<Vector3> v, List<int> t, Vector3 c, float rBot, float rTop, float h, int seg, float angOff = 0f)
        {
            AddPrism(v, t, c, new Vector2(rBot, rBot), new Vector2(rTop, rTop), h, seg, angOff);
        }

        public static void AddRing(List<Vector3> v, List<int> t, Vector3 c, float radius, float width, int seg)
        {
            float step = Mathf.PI * 2f / seg, ri = radius - width, ro = radius + width;
            for (int i = 0; i < seg; i++)
            {
                float a0 = step * i, a1 = step * (i + 1);
                Quad(v, t,
                    new Vector3(c.x + Mathf.Cos(a0) * ri, c.y, c.z + Mathf.Sin(a0) * ri),
                    new Vector3(c.x + Mathf.Cos(a1) * ri, c.y, c.z + Mathf.Sin(a1) * ri),
                    new Vector3(c.x + Mathf.Cos(a1) * ro, c.y, c.z + Mathf.Sin(a1) * ro),
                    new Vector3(c.x + Mathf.Cos(a0) * ro, c.y, c.z + Mathf.Sin(a0) * ro));
            }
        }

        public static Mesh CreateMesh(List<Vector3>[] verts, List<int>[] tris)
        {
            var m = new Mesh();
            var all = new List<Vector3>();
            for (int s = 0; s < verts.Length; s++) all.AddRange(verts[s]);
            m.SetVertices(all);
            m.subMeshCount = verts.Length;
            for (int s = 0; s < verts.Length; s++)
            {
                int off = 0;
                for (int p = 0; p < s; p++) off += verts[p].Count;
                var idx = new List<int>(tris[s].Count);
                for (int i = 0; i < tris[s].Count; i++) idx.Add(tris[s][i] + off);
                m.SetTriangles(idx, s);
            }
            m.RecalculateNormals();
            return m;
        }

        public static GameObject AttachMesh(string name, Transform parent, Mesh mesh, Material[] mats)
        {
            var go = new GameObject(name);
            go.transform.SetParent(parent, false);
            go.AddComponent<MeshFilter>().sharedMesh = mesh;
            go.AddComponent<MeshRenderer>().sharedMaterials = mats;
            return go;
        }

        // 极简小装饰(血条/驻军光点等),单 submesh 小网格
        public static GameObject DecoBox(Material mat, Vector3 lpos, Vector3 size, Transform parent, string name = "deco")
        {
            var bv = new List<Vector3>(); var bt = new List<int>();
            AddBox(bv, bt, Vector3.zero, size);
            var mesh = CreateMesh(new List<Vector3>[] { bv }, new List<int>[] { bt });
            var go = AttachMesh(name, parent, mesh, new Material[] { mat });
            go.transform.localPosition = lpos;
            return go;
        }

        public static GameObject DecoQuad(Material mat, Vector3 lpos, Vector2 size, Transform parent, string name = "decoQ")
        {
            if (_quadMesh == null)
            {
                var v = new List<Vector3>(); var t = new List<int>();
                Quad(v, t, new Vector3(-0.5f, -0.5f, 0), new Vector3(0.5f, -0.5f, 0), new Vector3(0.5f, 0.5f, 0), new Vector3(-0.5f, 0.5f, 0));
                _quadMesh = CreateMesh(new List<Vector3>[] { v }, new List<int>[] { t });
            }
            var go = new GameObject(name);
            go.transform.SetParent(parent, false);
            go.transform.localPosition = lpos;
            go.transform.localScale = new Vector3(size.x, size.y, 1f);
            go.AddComponent<MeshFilter>().sharedMesh = _quadMesh;
            go.AddComponent<MeshRenderer>().sharedMaterial = mat;
            return go;
        }
    }
```

```csharp
using System.Collections.Generic;

namespace IronCurtain.Sim
{
    /// <summary>
    /// 兵团底座(M8.2a 第一批):1 主将 + 20 兵,兵随将走(4×5 阵型跟随);
    /// 主将死亡士兵永不溃逃、无将状态就近逐杀至死。纯 tick,无 UnityEngine 依赖。
    /// </summary>
    public static class RegimentSystem
    {
        public const int SoldiersPerGeneral = 20;
        public const int FormationRows = 4;   // 4 行 × 5 列,行列距 1.0 米
        public const int FormationCols = 5;

        public static SimVec2 FacingOf(Entity g)
        {
            var def = g.Side == Side.Blue ? new SimVec2(1f, 0f) : new SimVec2(-1f, 0f);
            if (g.HasMoveTarget)
            {
                var d = (SimVec2.FromGrid(g.MoveTarget) - g.PosF).Normalized();
                if (d.SqrMagnitude > 1e-8f) return d;
            }
            return def;
        }

        public static SimVec2 SlotOffset(Entity g, int slot)
        {
            var facing = FacingOf(g);
            var perp = new SimVec2(facing.Y, -facing.X);
            int row = slot / FormationCols;
            int col = slot % FormationCols;
            return facing * -(row + 1) + perp * (col - 2);
        }

        public static void Tick(SimCore sim, float dt)
        {
            // 快照遍历:士兵死亡结算会移除实体,禁止边枚举边修改
            var snapshot = new List<Entity>(sim.Entities.Values);
            foreach (var e in snapshot)
            {
                if (e.Kind != EntityKind.Unit || !e.IsSoldier || e.State == EntityState.Dead) continue;
                if (e.GarrisonBuildingId != 0) continue;

                var g = e.GeneralId != 0 ? sim.GetEntity(e.GeneralId) : null;
                if (g != null && g.Kind == EntityKind.Unit && g.State != EntityState.Dead)
                {
                    // a) 主将存活:阵型跟随(士兵不写 HasMoveTarget/State)
                    var target = g.PosF + SlotOffset(g, e.FormationSlot);
                    float dist = SimVec2.Distance(e.PosF, target);
                    if (dist > 0.2f) StepMove(e, target, dist, dt);
                }
                else
                {
                    // b) 无将续战:就近索敌逐杀至死(永不溃逃/撤退/响应指令)
                    var enemy = NearestEnemy(sim, e);
                    if (enemy == null) continue;
                    float dist = SimVec2.Distance(e.PosF, enemy.PosF);
                    if (dist <= e.Range + 0.3f) continue; // 交战交给 CombatUpdate
                    StepMove(e, enemy.PosF, dist, dt);
                }
            }
        }

        private static void StepMove(Entity e, SimVec2 target, float dist, float dt)
        {
            float spd = e.MoveSpeed * TerrainMap.MoveFactor(e.PosF);
            float step = System.Math.Min(spd * dt, dist);
            e.PosF = TerrainMap.ClampToEllipse(e.PosF + (target - e.PosF).Normalized() * step);
            e.Pos = e.PosF.ToGrid();
        }

        /// <summary>最近敌索敌:与 SimCore.FindNearestEnemy 同一欧氏语义(单位、非己方、非死亡、非城内/交换)。</summary>
        private static Entity NearestEnemy(SimCore sim, Entity e)
        {
            Entity best = null;
            float bestDist = float.MaxValue;
            foreach (var o in sim.Entities.Values)
            {
                if (o.Kind != EntityKind.Unit || o.Side == e.Side || o.State == EntityState.Dead) continue;
                if (o.GarrisonBuildingId != 0 || o.State == EntityState.Exchanging) continue;
                float d = SimVec2.Distance(e.PosF, o.PosF);
                if (d < bestDist) { best = o; bestDist = d; }
            }
            return best;
        }

        /// <summary>生成主将 + 20 名士兵的完整兵团,返回主将实体。</summary>
        public static Entity SpawnGeneral(SimCore sim, Side side, HeroId hero, GridPos pos)
        {
            var c = sim.Game.Heroes[(int)hero];
            var anchor = SimVec2.FromGrid(pos);
            // 朝向探针:仅用于出生时计算槽位偏移(默认朝向,与主将无移动目标时一致)
            var probe = new Entity(0, side, EntityKind.Unit, pos, 0f);

            // 先生成士兵(每生成一名立即摆到槽位,避免同点出生距离校验冲突),主将最后落位
            var soldiers = new List<Entity>(SoldiersPerGeneral);
            for (int slot = 0; slot < SoldiersPerGeneral; slot++)
            {
                var s = sim.SpawnEntity(side, EntityKind.Unit, pos);
                s.IsSoldier = true;
                s.FormationSlot = slot;
                s.Hero = hero; // 供类型与渲染(伤害英雄规则 M8.2b 收口,本轮已知)
                s.MaxHp = c.MaxHp / 10f;
                s.Hp = s.MaxHp;
                s.Attack = c.Attack / 10f;
                s.AttackIntervalSec = (float)c.AttackIntervalSec;
                s.MoveSpeed = (float)c.MoveSpeed;
                s.Range = c.Range;
                s.Shield = c.Shield / 10f;
                s.ShieldMax = s.Shield;
                s.PosF = anchor + SlotOffset(probe, slot);
                s.Pos = s.PosF.ToGrid();
                soldiers.Add(s);
            }

            var g = sim.SpawnEntity(side, EntityKind.Unit, pos);
            g.Hero = hero;
            g.MaxHp = c.MaxHp;
            g.Hp = c.MaxHp;
            g.Attack = c.Attack;
            g.AttackIntervalSec = (float)c.AttackIntervalSec;
            g.Range = c.Range;
            g.MoveSpeed = (float)c.MoveSpeed;
            if (c.Shield > 0) { g.Shield = c.Shield; g.ShieldMax = c.Shield; }

            foreach (var s in soldiers) s.GeneralId = g.Id;
            return g;
        }
    }
```
