# M0.2 数值配置 —— GDD 全表 → GameConfig + JSON + 校验器

## 一、角色与任务
你是《铁幕:前线》Unity 6 项目的数值系统主程。本模块把 GDD 全部数值表落成**强类型配置**:纯 C# POCO + System.Text.Json 解析 + 自检校验器 + 对表单元测试。后续所有模块只读 GameConfig,禁止在代码里硬编码数值。
只新增文件,**不得修改**任何 M0.1 已交付文件(SimCore/Entity/SeededRng/LaneGrid/SimConfig/SimEvent/ICommand/GridPos/SimBootstrapper/三个 asmdef/SimSmokeTests)。

   - 关键数值对表:镇岳 MaxHp==200 Attack==14;磐石 Shield==140;箭塔 Attack==18 Splash==12 Interval==2.5 Range==5;Match.BaseHp==200
7. `Assets/Resources/gameconfig.json`:完整 JSON,根为 GameConfig 结构,所有字段必须填满(描述类字段可简洁),数值严格按第二节表格。

   - Tools.RamDamage==15、FortHp==30;TowerGarrison.AttackPerGarrison==2

## 五、硬性验收
1. 单文件 ≤300 行(GameConfig.cs 会超就拆 POCO 与根类)
2. Sim 层禁止 using UnityEngine;测试层允许
3. JSON 与 POCO 字段一一对应,不得遗漏字段
4. 数值与本提示词第二节逐字一致(尤其:镇岳 200/14/2s/2人口;星落 5攻1s间隔;箭塔 18/12/2.5s/5格;EP 上限5;升级 2EP;抽卡 2EP)
5. 星落不得出现任何"降产/production debuff"字段
6. 全部测试编译且通过

## 六、输出格式
只输出文件,禁止解释、禁止 Markdown 围栏。每个文件以 `// FILE: <相对项目根路径>` 开头后接完整内容。所有 8 个文件一次给全。
