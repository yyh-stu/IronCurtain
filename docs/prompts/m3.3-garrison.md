# M3.3 驻军完整系统 —— 正式/临时驻军、依托射击、出击、撤出、建筑回复(GL M 绿场实现+测试)

## 一、角色与任务
你是《铁幕:前线》Unity 6 项目驻军系统主程。本模块实现完整驻军机制。只新增两个文件:`Assets/Scripts/Sim/GarrisonSystem.cs` 与 `Assets/Tests/EditMode/GarrisonTests.cs`。**禁止修改任何既有文件**(70 个既有测试必须保持全绿)。

## 二、规则(权威,GDD + 拍板)
- GDD 2.4:正式驻军单建筑最多 9(配置 GarrisonFormal),不占线单位身位;临时驻军单建筑上限 9;临时驻军停留满 10 秒未手动派出,系统强制沿当前路线向前行军;正式驻军空缺时自动补入。
- GDD 2.4.1:正式+临时驻军同时存在时,敌方优先消耗临时驻军(交换消耗顺序已在 SiegeSystem 实现,本模块只需正确维护两个列表)。
- D24(用户拍板):Exit 撤出——每次放该兵种一只到城门站定(Idle 原地待命)。
- D26(用户拍板):攻击优先级——单位优先于建筑(本模块只影响"近战驻军出击"触发)。
- D27(用户拍板):建筑脱战回复——非大本营,20 秒未被攻击后 4/秒 回血至上限。
- D28(编排默认,实现按此):行军途经己方建筑自动临时驻军(见契约)。
- 远程英雄依托建筑向外射击;近战驻军可主动出击迎敌。

## 四、接口契约(严格实现)

### GarrisonSystem.cs(`namespace IronCurtain.Sim`,静态类)
```csharp
public static bool EnterFormal(SimCore sim, IReadOnlyList<int> unitIds, int buildingId, out string error);
// 建筑须为己方(Side==单位.Side)、CanGarrison(配置)、正式<9;每单位入城:FreeCell(单位.Pos)、
// GarrisonBuildingId=buildingId、State=Idle、HasMoveTarget=false、加入 GarrisonFormal;超员单位报 error="正式驻军已满"
public static bool EnterTemp(SimCore sim, IReadOnlyList<int> unitIds, int buildingId, out string error);
// 同上但上限 GarrisonTemp(9);入 GarrisonTemp
public static bool Exit(SimCore sim, int buildingId, HeroId hero, out string error);  // D24
// 优先正式列表,其次临时列表;找该兵种一只:移出列表,城门站定(城门=建筑朝敌侧邻格,行序1/0/2,全占则本侧向外≤8 列;
// 找到空位:单位 Pos=该格、GarrisonBuildingId=0、State=Idle、清 MoveTarget;找不到空位 error="城门无空位")
public static void Tick(SimCore sim, float dt);
// 1) 临时驻军计时:每个 GarrisonTemp 单位累计停留秒数(本模块内部 Dictionary<int,float>),满 10 秒:
//    若该建筑正式驻军<9 → 转正式(移表/计时清除);否则强制行军:城门站定+继续原路线(Exit 同款城门逻辑,State=Moving,
//    SetMoveTarget 到集结点 RallyPointOf(建筑.Side))
// 2) 依托射击:遍历建筑,远程驻军单位(Hero∈{坠日,星落}):以建筑格为原点,射程=单位 Range,
//    间隔=单位 AttackIntervalSec;索敌(曼哈顿,平局小 id)命中:DamageCalculator.CalculateDamage(单位,目标,cfg,false)
//    先护盾后血量(照抄主循环顺序);只打敌军单位(排除驻军/Exchanging/Dead)
// 3) 近战出击:近战驻军(Hero∉{坠日,星落})在敌单位曼哈顿≤2 时出城:城门站定,State=Idle(战斗由主循环自动接战)
// 4) 建筑回复(D27):非大本营建筑 SecondsSinceCombat += dt;≥20 时 Hp = min(MaxHp, Hp + 4*dt)
// 5) 驻军单位 SecondsSinceCombat 不回血、不移动、不参战(主循环已跳过 GarrisonBuildingId!=0)
```

### GarrisonTests.cs(EditMode,[Test] 10 个)
SetUp 照抄既有模式;蓝兵营 (1,2),蓝箭塔 (1,6),红箭塔 (1,22)。
1. 正式入城:3 只 EnterFormal 蓝兵营 → GarrisonFormal.Count==3;单位 GarrisonBuildingId==兵营 id;原格被 FreeCell(新单位可生成在该格)
2. 正式满员:第 10 只 EnterFormal → error 含"已满",第 9 只成功
3. 临时驻军 10 秒转正式:兵营正式 0,3 只 EnterTemp → 100 tick 后全转正式(GarrisonFormal==3, Temp==0)
4. 临时满员强制行军:正式已 9,2 只 EnterTemp → 100 tick 后 Temp 空、单位 State==Moving、MoveTarget==RallyPointOf
5. Exit 撤出一只:正式 [磐石,磐石,坠日],Exit(坠日) → 坠日离城(城门格、Idle),磐石×2 仍在
6. Exit 城门无空位:城门 3 格全占 → Exit 返回 error 含"无空位"
7. 依托射击:红箭塔驻军坠日×1,蓝磐石在 (1,11)(距塔 5,坠日射程 5)→ 每 2 秒一箭:100 tick 内磐石盾下降(10×0.7=7/箭)
8. 近战出击:红箭塔驻军断峰×1,蓝单位进到距离 2 → 断峰出城(城门格、GarrisonBuildingId==0)
9. 建筑回复:蓝箭塔 Hp 打到 20(直接改 Hp),SecondsSinceCombat 设 25 → 50 tick 后 Hp==40(20+4×5)
10. 大本营不回复:蓝大本营 Hp 打到 50,SecondsSinceCombat 设 25 → 100 tick 后仍 50
