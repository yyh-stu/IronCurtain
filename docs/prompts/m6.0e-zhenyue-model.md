# 镇岳首模 bpy 建模脚本(M6.0e 第一单:AI 底模管线首模)

## 一、角色与任务

你是资深 Blender 技术美术(写 bpy Python 脚本)。本任务:生成一个**单文件**建模脚本 `zhenyue_build.py`,在 Blender 4.5 无头模式(`blender.exe --background --python zhenyue_build.py`)下一次执行完成:建模 → 保存 .blend → 渲染四视图 PNG → 导出 FBX → 打印统计后正常退出。

红线:单文件 ≤300 行;只用 Blender 4.5 内置 API(bpy/mathutils/bmesh),不装插件不联网;所有部件**独立命名对象**+**非破坏修改器**(Subsurf/Bevel/Mirror/Boolean 均可,不做破坏性编辑),供人工后续在 Blender 里调参;不写任何中文注释以外的输出文本;脚本幂等(重复执行结果一致,先清空场景)。

## 二、建模规格(全部为硬约束,逐字执行)

**角色人设**:镇岳——肌肉量大、壮实的西方式铠甲战士(卡通风格结构,写实修长比例)。

**全局参数**:
- 单位:1 Blender 单位 = 1 米;**总身高(脚底到盔顶)= 1.92m**(同系列其他将领未来按 1.6m,形成 +20% 高大差)
- 头身比:头高(含盔)≈ 身高/7 ≈ 0.275m;头宽 ≈ 0.22m
- 肩宽 = 头宽 × 2.5(桶状壮实轮廓:肩宽≈臀宽,腰腹略收,四肢粗壮)
- 胸厚(前后深度)≈ 头高 × 0.6;腿长(髋至脚底)≈ 身高 × 0.55
- 姿势:A-pose 静态站姿(双臂自然下垂、离身体约 15°),右手持锤(锤竖立拄地,锤头朝上)
- 面数预算:**全模型 ≤ 8000 三角面**(导出 FBX 时 apply 所有修改器后统计)
- 原点:全模型组合的原点 = 脚底中心;朝向:面朝 -Y(Blender 前视图惯例,FBX 导出后 Unity 面朝 +Z 由导出器处理)

**部件清单(每件独立对象,命名前缀 ZhenYue_,相对尺寸来自三视图 v1 结构清单,已按用户拍板修正)**:
1. `ZhenYue_Helmet` 全覆式头盔:截顶圆锥+矩形面罩的卡通化块状;盔顶**纵向棱脊**(user 拍板,必须明显);目缝=横向长条开口(宽≈盔宽 1/3,高≈盔高 1/5,可用深色内嵌薄块表现,不掏洞);贴头无悬空;护颈=U 型弧面从下巴延至肩上,厚≈胸甲 1/2。
2. `ZhenYue_Chest` 胸甲:梯形+矩形组合、上窄下宽底部外扩;**厚实膨出**(不是贴身紧身衣!甲板本身有厚度,把人撑壮——这是用户特别强调:铠甲块状有体积,不是包肌肉皮);双层叠视(主胸甲+前襟重叠片),锁骨至腹底有 V 型棱线。
3. `ZhenYue_Pauldron_L/R` 肩甲×2:圆盖+斜切边缘的翼状外扩;宽≈头宽 1.5 倍,高≈头高 0.8 倍;外侧超出躯干轮廓约 1/4 肩宽。
4. `ZhenYue_UpperArm_L/R` 上臂甲:圆柱套筒,两端环形收束。
5. `ZhenYue_Elbow_L/R` 肘甲:梯形块,前凸后平,厚≈上臂甲 1.2 倍。
6. `ZhenYue_Forearm_L/R` 前臂甲:两段阶梯圆柱,下段收窄接拳甲。
7. `ZhenYue_Fist_L/R` 全覆式金属拳甲:块状拳套,拇指独立外展,四指合并,前端圆钝。
8. `ZhenYue_Skirt` 腰裙甲:两层——内层矩形短裙+外层梯形垂片(前中与两侧分片),垂片下缘至大腿中部(膝上 1/3);后摆 V 型开口。
9. `ZhenYue_Thigh_L/R` 大腿甲:梯形块前凸后平。
10. `ZhenYue_Knee_L/R` 膝甲:菱形块中心凸起。
11. `ZhenYue_Shin_L/R` 小腿甲:锥柱组合(上圆柱下收窄)。
12. `ZhenYue_Boot_L/R` 靴甲:梯形块+圆头,前掌宽于脚跟,脚踝环形束带,鞋底略厚。
13. `ZhenYue_Hammer` 战锤(独立对象,右手位):锤头=**宽 ≥ 头宽×1.3 的长方体+斜面倒角**(用户拍板,必须明显大于头部),锤面平滑**无尖刺无倒刺**;**全钢无木柄**(user 拍板,柄也是钢材质);柄长≈身高×0.5,圆柱中段略粗两端略细;拄地竖立姿态。
14. `ZhenYue_Body` 内衬身体(深色):填在甲内部的基本人体块(圆柱四肢+块状躯干),露出的颈下/大腿内侧部分为深色;**禁止布带、披风、腰带挂饰等任何额外物件**(user 拍板:无)。

**材质(占位,两档)**:钢件(Helmet/Chest/Pauldron/臂/拳/裙/腿/靴/Hammer 全部)= Principled BSDF,Base Color RGB(0.72, 0.74, 0.78),Metallic 0.85,Roughness 0.35;深色内衬(Body)= Base Color RGB(0.12, 0.12, 0.13),Metallic 0.1,Roughness 0.7。

**渲染(四视图,EEVEE_NEXT)**:1920×1080;四相机:前(-Y 看向+Y)、侧(+X 看-X)、背(+Y 看-Y)、透视(斜 45° 高俯);每视图都能框住全身(目标物高 1.92m,相机距离/焦距按此计算,留 10% 边距);三点光照(主光+补光+轮廓光,强度适中,卡通明快);纯浅灰背景(RGB 0.82);输出:
- `D:/DevTools/美术资产仓库/00_台账/过程存档/四视图渲染/镇岳_v1_前.png`(_侧/_背/_透视 同理)

**导出**:
- .blend 保存到 `D:/DevTools/美术资产仓库/00_台账/过程存档/底模脚本/镇岳_v1.blend`
- FBX:`bpy.ops.export_scene.fbx` 到 `D:/DevTools/美术资产仓库/03_3D建模/IronCurtain/镇岳/镇岳_v1.fbx`,apply modifier/默认参数,path_mode COPY 不需要(无贴图)。

**执行末尾 print 统计**(供程序化验收):`BUILD_OK parts=<对象数> tris=<apply 后总三角面> height=<实际身高米数>`,并确保目录已创建(os.makedirs exist_ok)。

## 三、验收(程序化)

2. tris ≤ 8000,height ∈ [1.90, 1.94];
3. 产 4 张 PNG(非空)+ 1 FBX + 1 .blend;
4. 人工复核(用户)在四视图之后,脚本不负责。
