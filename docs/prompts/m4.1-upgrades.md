## 二、升级规则(权威)
- 2 EP 购买,单英雄每局仅一次,全程永久,同类兵团同步加成。
- 磐石·坚定:完全免疫减速、沉默、重伤。
- 镇岳·迅捷:移速固定 2.2 格/s(覆盖 3 分钟衰减),生产时间缩短至 7.5 秒。**基础镇岳 3 分钟后移速衰减至 1.4 格/s(D11 默认)。**
- 断峰·破军:单次伤害 ×75%,攻击身前 90° 扇形(半径 2 格内全部敌人)——主目标吃全额,扇形内其余敌人吃 75%。
- 逐风·飞掠:拆塔 7/s(替代 3/s);非战斗途经敌方建筑不被塔锁定(State!=Attacking 时塔不索敌)。
- 坠日·诛心:攻击镇岳附加脆弱(承伤 +10%,3 秒)。
- 星落·诛灭:基础攻击 5→6,额外附加目标最大生命 1% 伤害。

EP 注入方法(测试用):`sim.SpendEp` 只能减——给某一方凑 EP 的办法:为其生成 1 座资源点建筑 `sim.SpawnBuilding(side, BuildingId.ResourcePoint, pos)`,再跑 900 tick(每座每 90 秒 +1)。买 2 EP 需要 2 座资源点跑 900 tick。
生成英雄单位标准写法(照抄,double→float 显式转):
```csharp
var c = sim.Game.Heroes[(int)heroId];
var u = sim.SpawnEntity(side, EntityKind.Unit, pos);
u.Hero = heroId; u.MaxHp = c.MaxHp; u.Hp = c.MaxHp; u.Attack = c.Attack;
u.AttackIntervalSec = (float)c.AttackIntervalSec; u.Range = c.Range; u.MoveSpeed = (float)c.MoveSpeed;
if (c.Shield > 0) { u.Shield = c.Shield; u.ShieldMax = c.Shield; }
```

## 四、要写的测试([Test] 9 个)
1. **购买扣费与一次性**:蓝方 2 资源点跑 900 tick → EP 2;BuyUpgrade(蓝,磐石) 成功且 EP 归 0;重复购买返回 false 且 error 含"已升级";EP 不足时买第二个返回 false 且 error 含"EP"
2. **磐石免疫**:升级磐石;星落普攻升级磐石 → 无 Silence;断峰普攻 → 无 Slow;坠日不触发(坠日只打镇岳)——用前两者即可;对照:未升级磐石照常被沉默(用另一只未升级…注意升级是整方,用红方未升级磐石对照)
3. **镇岳迅捷**:升级镇岳,3 分钟(tick 1800)后其移速仍为 2.2(SetMoveTarget 后实测格速:60 tick 走 2.2 格?10tick/格×2.2……直接测 MoveSpeed 生效:设目标,Step 10 → MoveAccum/位移——更简单:断言 tick≥1800 后单位移动 10 tick 位移 2.2 格);对照未升级镇岳 tick≥1800 后 10 tick 位移 1.4 格
4. **镇岳产速 7.5s**:升级镇岳,Enqueue → 75 tick 出(对照未升级 90 tick)
5. **断峰破军**:升级断峰;主目标(正前方 1 格)吃全额 14;扇形内另一敌(前方 2 格或侧前 1 格)吃 75%(14×0.75=10.5);身后 1 格敌不吃
6. **逐风飞掠拆塔 7/s**:升级逐风,拆塔 → 每击 14(7×2s)(对照未升级每击 6)
7. **飞掠不锁塔**:升级逐风(红方)从蓝塔射程内经过(State!=Attacking)→ 100 tick 不掉血;对照未升级逐风同场景掉血
8. **坠日诛心**:升级坠日打镇岳 → 镇岳 Has(Fragile)==true;后续承伤 +10%(用另一攻击者打镇岳,伤害 ×1.1)
9. **星落诛灭**:升级星落打满盾磐石(盾 140):每击 = 6×0.5 + 0.01×80 = 3.0 + 0.8 = 3.8(盾掉 3.8);对照未升级每击 2.5
