# M0.1 工程地基 —— Sim 确定性核心 + 分层骨架

## 一、角色与任务
你是 Unity 6(6000.0.30f1 LTS)资深主程,正在为 1v1 轻量 RTS《铁幕:前线》搭建工程地基。
本模块只做一件事:**建立三层程序集骨架与纯 C# 确定性模拟核心**(不含任何战斗/移动/数值逻辑,那些是后续模块)。
目标:Sim 层零 UnityEngine 依赖,可被 Unity Test Framework 与无头环境直接驱动。

## 二、GDD 原文摘录(仅本模块相关)
> 2.2 线单位战场空间:两座相邻建筑之间为独立线单位,三条路线互不干扰。单个线空间规格为三排三十格,每格容纳一个英雄身位,单条路线最大承载九十单位。所有英雄移动、交战均在线单位内完成,移速单位为格 / 秒。

### 3.2 Sim 层(`namespace IronCurtain.Sim`,禁止 using UnityEngine)
- `enum Side { Blue = 0, Red = 1 }`
- `enum EntityKind { Unit, Building }`
- `struct GridPos` : Row(0..2)、Col(0..29),含 `bool IsValid`、`==`/`!=`、`ToString()`
- `sealed class LaneGrid`:常量 Rows=3、Cols=30、MaxUnits=90;`bool InBounds(GridPos)`;`int ToIndex(GridPos)`
- `sealed class SimConfig`:TickRate=10(默认)、LaneRows=3、LaneCols=30、MaxUnitsPerLane=90,全 int 字段+构造参数
- `sealed class SeededRng`:构造传入 ulong seed;`ulong NextUInt64()`(xorshift64* 实现);`int NextInt(int minInclusive,int maxExclusive)`;`double NextDouble01()`。同一 seed 两次构造,序列必须完全一致。禁止 System.Random。
- `sealed class Entity`:Id(int)、Side、Kind、Pos(GridPos)、Hp(float,默认由调用方设)。构造:id、side、kind、pos。
- `enum SimEventType { StepBegin, StepEnd, EntitySpawned, EntityRemoved, CommandExecuted }`
- `struct SimEvent`:long Tick、SimEventType Type、int SubjectId。含 `ToString()`。
- `interface ICommand { void Execute(SimCore sim); }`
- `sealed class SimCore`:
  - 构造:`SimCore(SimConfig config, SeededRng rng)`
  - 属性:`long Tick`、`SimConfig Config`、`SeededRng Rng`、`int EntityCount`
  - `Entity SpawnEntity(Side side, EntityKind kind, GridPos pos)`(分配自增 Id,发 EntitySpawned 事件,返回实体;若同格已占用抛 InvalidOperationException)
  - `bool RemoveEntity(int id)`(存在则移除并发 EntityRemoved,返回 true)
  - `Entity? GetEntity(int id)`(找不到返回 null,项目 C# 版本支持可空引用;若不熟可空注解就返回 Entity 并允许 null 语义,但必须编译通过)
  - `void SubmitCommand(ICommand cmd)`(入队,不立即执行)
  - `void Step()`:Tick+1 → 依次执行队列中所有命令(每条发 CommandExecuted)→ 发 StepEnd;Step 开始发 StepBegin。执行顺序:StepBegin → commands → StepEnd。
  - `void AddEventListener(Action<SimEvent> listener)`、`void ClearEventListeners()`:监听器在事件产生时同步回调。

### 3.3 View 层(`namespace IronCurtain.View`)
- `SimBootstrapper : MonoBehaviour`:
  - `public SimCore Sim { get; private set; }`
  - Awake:new SimConfig() 默认值 + new SeededRng(seed: 42)→ new SimCore → 打印 "SimCore ready" (Debug.Log)
  - 固定步长:用累加器以 10Hz 驱动 Sim.Step()(基于 Time.fixedDeltaTime 或 Time.deltaTime 累加,不依赖物理帧率);step 间隔 = 1.0/TickRate 秒
  - 暂停/恢复:`public bool Paused`
  - OnDestroy:清空监听器

### 3.4 测试层(`IronCurtain.Tests`,EditMode)
- `SimSmokeTests`:4 个 [Test]:
  1. 连续 Step() 5000 次无异常且 Tick==5000
  2. Spawn/Remove:生成 3 个实体,EntityCount==3;移除 1 个后==2;同格重复生成抛异常
  3. SeededRng 确定性:两个相同 seed 实例各取 1000 个 NextInt(0,100),序列逐位相等;不同 seed 序列不同
  4. LaneGrid:中心点合法;(-1,0)/(3,29)/(0,30) 非法
- 测试只依赖 Sim 层 + NUnit,不依赖任何场景对象。

## 四、现状
项目为全新 Unity 工程(内置渲染管线),`Assets/` 为空,无任何脚本。本模块所有文件均为新建。

## 五、硬性验收
1. Sim 层任何文件不得出现 `using UnityEngine`/`UnityEngine.`(asmdef noEngineReferences 会强制拦截)
2. 全部文件按契约编译通过(含测试程序集)
3. 单个文件 ≤ 300 行;超出的拆类
4. 禁止 async/await、禁止 System.Random、禁止 Time/DateTime.Now(时间一律用 Tick 表示)
5. 注释用简洁中文,只解释"为什么",不解释"是什么"

## 六、输出格式
只输出文件,禁止任何解释文字、禁止 Markdown 代码围栏。每个文件以一行 `// FILE: <相对于项目根的路径>` 开始,随后是该文件完整内容。asmdef 三份按 3.1 原文输出。所有文件一次给全。
