你是《铁幕:前线》Unity 6(6000.0.30f1,URP 17)表现层主程。用户否决了程序化自建网格,拍板改用**现成 CC0 卡通低模资产(Kenney 系列)**,整体画风对标《部落冲突》式卡通低模。本模块**只重写以下 2 个文件**:
- `Assets/Scripts/View/EntityView.cs`(实体模型改为加载 Kenney FBX 资产)
- `Assets/Scripts/View/BoardView.cs`(地面装饰:树/岩石撒布)

禁止修改任何其他文件(GameBootstrap/MatchSetup/CaptureRunner/ViewAssets/Sim 层/测试全部)。**单文件 ≤300 行**;命名空间 `IronCurtain.View`;Sim 层数据只读。

- 贴图:FBX 自带材质(导入时已按贴图生成),URP/Lit 兼容。

## 三、渲染规格(权威)

### 3.1 加载与组合
- 每个 EntityView 的模型层:创建 `GameObject("Model")`,Instantiate 若干 FBX 子模型,组合成建筑/单位。
- **尺寸归一化**:FBX 导入尺寸不一,统一用 bounds 归一:`float s = targetH / bounds.size.y; child.transform.localScale = Vector3.one * s;`,再按组合摆放。组合后整体再统一缩放,确保:单位总高 ≈1.6m;建筑总高:大本营 4.5m / 兵营 2.6m / 箭塔 3.4m / 资源点 2.8m。
- 所有子模型 y 从 0 起堆叠(下件 top = 上件 bottom),简单按件高累加,不看 bounds 精准对齐,允许小缝隙。

### 3.2 建筑映射(组合清单)
- **大本营 Base**:tower-square-base(底)+ tower-square-mid(中)+ tower-square-top-roof(顶)。整体高 4.5m。
- **箭塔 Tower**:tower-hexagon-base + tower-hexagon-mid + tower-hexagon-roof。整体高 3.4m。
- **兵营 Barracks**:tower-square-mid-door(带门主体,门朝 +z)+ tower-square-roof。整体高 2.6m。门前放一支小旗帜:用程序化小 Quad(竖杆+三角旗,阵营色,复用 ViewAssets.DecoQuad/Box 即可)。
- **资源点 ResourcePoint**:windmill(风车,蓝/红方);**中立资源点**:watermill(水磨坊)。
- **堡垒 IsFort**:stall(小摊棚)+ 顶上一圈阵营光点(程序化 3 个小发光方块)。
- 红方建筑与蓝方同件,**阵营区分**靠:底部阵营光环盘(程序化,保留现实现)+ 建筑旁插一面阵营小旗(程序化 Quad,蓝=青、红=红、中立=灰绿)。不换贴图、不 tint 建筑本体。
- **废墟 Rubbled**(SetRubbled(true)):隐藏正常模型,Instantiate 对应残骸:大本营/箭塔/兵营 → siege-tower-demolished;资源点 → cart(翻倒小车)+岩石。整体 y×0.9,附 3 个 rocks-small 散件。SetRubbled(false) 恢复原模型。
- 中立建筑(non-resource,如演示用)主体灰白:给子模型 renderer 换 `ViewAssets.Flat(Color(0.62,0.62,0.60))` 材质实例(覆盖贴图,保持剪影)。

### 3.3 单位映射(六英雄,暂用 Kenney 角色占位,后续将替换为机甲模型——因此英雄→角色映射集中在一个静态函数,方便替换)
- PanShi 磐石 → character-a;ZhenYue 镇岳 → character-b;DuanFeng 断峰 → character-c;ZhuFeng 逐风 → character-d;ZhuiRi 坠日 → character-e;XingLuo 星落 → character-f。
- 总高 ≈1.6m;朝向:蓝面 +x(rotation y=90°)、红面 -x(y=-90°);角色自带贴图,阵营 tint:给角色 renderer 材质实例 `_BaseColor` 乘以阵营色(蓝 (0.8,0.9,1)、红 (1,0.85,0.85)),只 tint 不换贴图。
- 底部阵营光环盘:程序化扁圆柱(半径 0.85m,GlowMat 强发光),保留。
- 驻军单位(GarrisonBuildingId!=0):隐藏模型(建筑顶部光点逻辑保留在 Tick)。
- 死亡缩隐(SetDead)、血条、护盾条:全部保留现行为。

### 3.4 地面装饰(BoardView)
- 保留:6×255 棋盘合并网格、废土延展面、南北发光围栏、东西短墙、中央暗金中线。
- **新增环境撒布**(固定种子 System.Random(1234),共 24 件):沿棋盘两侧(z=+4.2 与 z=-4.2 带)随机 x∈[3,252] 撒布:tree-large ×4、tree-small ×6、rocks-large ×4、rocks-small ×10;每件随机 yaw;高度归一(tree ≈2.2m,rock ≈0.7m);全部 Instantiate 到 Board 下 `Environment` 子节点。不遮挡建筑列(建筑列 3/34/65/96/127/158/189/220/251 的 ±2 格内不撒)。

### 3.5 保留不动的现有逻辑
- `Tick` 平滑插值(单位 PosF / 建筑 Pos)、血条 SetHp/UpdateShield/TickBillboard、驻军光点 UpdateGarrison、FlashHit 空方法、SetDead 缩隐、事件接线、相机/Bloom/灯光(GameBootstrap 不动)、MatchSetup/CaptureRunner 不动。

### 4.1 EntityView.cs 全文
```csharp
using System.Collections.Generic;
using IronCurtain.Sim;
using UnityEngine;

namespace IronCurtain.View
{
    public sealed class EntityView : MonoBehaviour
    {
        private Entity _e;
        private Side _side;
        private GameObject _model, _gr, _chunks;
        private MeshRenderer _mr;
        private Material[] _mats;
        private Transform _hpRoot, _hpFill, _shFill;
        private float _w = 1.7f, _h = 0.26f, _deadT = -1f, _topY = 3.5f;
        private bool _dead, _rubbled;
        private int _gf = -1, _gt = -1;
        private Material _g, _y, _r, _bk, _sh, _rub, _rubG, _gA, _gB;

        public void Bind(Entity e, Side side, HeroId? hero, BuildingId? building)
        {
            _e = e; _side = side;
            InitMats();
            if (e.Kind == EntityKind.Unit) BuildUnit(hero.HasValue ? hero.Value : HeroId.PanShi);
            else BuildBuilding(building.HasValue ? building.Value : BuildingId.Tower);
            BuildHpBar();
            transform.position = e.Kind == EntityKind.Building ? BoardView.WorldPos(e.Pos) : BoardView.WorldPos(e.PosF);
            if (e.Kind == EntityKind.Unit)
                transform.rotation = Quaternion.Euler(0f, side == Side.Blue ? 90f : -90f, 0f);
        }

        private void InitMats()
        {
            if (_g != null) return;
            _bk = ViewAssets.Flat(new Color(0.06f, 0.06f, 0.07f));
            _g = ViewAssets.Mat(Color.green, 0f, 0.4f, Color.green, 0.8f);
            _y = ViewAssets.Mat(new Color(1f, 0.85f, 0f), 0f, 0.4f, new Color(1f, 0.85f, 0f), 0.8f);
            _r = ViewAssets.Mat(Color.red, 0f, 0.4f, Color.red, 0.8f);
            _sh = ViewAssets.Mat(new Color(0.4f, 0.8f, 1f), 0f, 0.4f, new Color(0.4f, 0.8f, 1f), 1.2f);
            _rub = ViewAssets.Flat(new Color(0.24f, 0.22f, 0.20f));
            _rubG = ViewAssets.Flat(new Color(0.15f, 0.14f, 0.13f));
            _gA = ViewAssets.Mat(Color.black, 0f, 0.9f, new Color(1f, 1f, 0.9f), 2.2f);
            _gB = ViewAssets.Mat(Color.black, 0f, 0.9f, new Color(0.4f, 0.4f, 0.4f), 0.7f);
        }

        public void FlashHit() { }

        public void SetDead()
        {
            if (_dead) return;
            _dead = true; _deadT = 0f;
        }

        public void SetRubbled(bool on)
        {
            if (_rubbled == on || _model == null) return;
            _rubbled = on;
            _mr.sharedMaterials = on ? new Material[] { _rub, _rubG } : _mats;
            _model.transform.localScale = on ? new Vector3(1f, 0.35f, 1f) : Vector3.one;
            if (_chunks != null) { Destroy(_chunks); _chunks = null; }
            if (on)
            {
                _chunks = new GameObject("RubbleChunks");
                _chunks.transform.SetParent(_model.transform, false);
                for (int i = 0; i < 3; i++)
                {
                    float a = i * 2.1f + 0.7f;
                    ViewAssets.DecoBox(_rubG, new Vector3(Mathf.Cos(a) * 1.2f, 0.12f, Mathf.Sin(a) * 1.2f),
                        new Vector3(0.5f + i * 0.2f, 0.25f, 0.4f + i * 0.15f), _chunks.transform, "chunk" + i);
                }
            }
        }

        public void SetHp(float hp, float maxHp)
        {
            if (_hpFill == null) return;
            float t = maxHp > 0f ? Mathf.Clamp01(hp / maxHp) : 0f;
            bool show = _e.Kind == EntityKind.Building || t < 0.999f;
            _hpRoot.gameObject.SetActive(show);
            _hpFill.localScale = new Vector3(_w * t, _h, 1f);
            _hpFill.localPosition = new Vector3(-_w * (1f - t) * 0.5f, 0f, 0f);
            _hpFill.GetComponent<MeshRenderer>().sharedMaterial = t > 0.5f ? _g : (t > 0.25f ? _y : _r);
        }

        public void TickBillboard(Camera cam)
        {
            if (_hpRoot != null && cam != null)
                _hpRoot.rotation = Quaternion.LookRotation(_hpRoot.position - cam.transform.position);
        }

        public void Tick(float dt, Camera cam)
        {
            if (_e == null) return;
            bool isB = _e.Kind == EntityKind.Building;
            bool hidden = !isB && _e.GarrisonBuildingId != 0;
            if (_model.activeSelf != !hidden) { _model.SetActive(!hidden); _hpRoot.gameObject.SetActive(!hidden); }
            if (!hidden)
            {
                Vector3 target = isB ? BoardView.WorldPos(_e.Pos) : BoardView.WorldPos(_e.PosF);
                if (isB) transform.position = target;
                else transform.position = Vector3.Lerp(transform.position, target, 1f - Mathf.Exp(-14f * dt));
                SetHp(_e.Hp, _e.MaxHp);
            }
            if (_e.Rubbled && !_rubbled) SetRubbled(true);
            if (!_e.Rubbled && _rubbled) SetRubbled(false);
            if (isB) UpdateGarrison();
            UpdateShield();
            TickBillboard(cam);
            if (_dead)
            {
                _deadT += dt;
                float s = Mathf.Max(0.01f, 1f - _deadT * 4f);
                transform.localScale = Vector3.one * s;
            }
            else transform.localScale = Vector3.one;
        }

        private void UpdateGarrison()
        {
            int f = _e.GarrisonFormal.Count, t = _e.GarrisonTemp.Count;
            if (f == _gf && t == _gt) return;
            _gf = f; _gt = t;
            if (_gr != null) Destroy(_gr);
            _gr = null;
            if (f + t == 0) return;
            _gr = new GameObject("Garrison");
            _gr.transform.SetParent(_model.transform, false);
            int n = f + t;
            for (int i = 0; i < n; i++)
            {
                float a = i / (float)Mathf.Max(1, n) * Mathf.PI * 2f;
                ViewAssets.DecoBox(i < f ? _gA : _gB,
                    new Vector3(Mathf.Cos(a) * 1.15f, _topY, Mathf.Sin(a) * 1.15f),
                    Vector3.one * 0.2f, _gr.transform, "d" + i);
            }
        }

        private void UpdateShield()
        {
            if (_shFill == null) return;
            bool show = _e.Shield > 0.01f && _e.ShieldMax > 0.01f;
            _shFill.gameObject.SetActive(show);
            if (show)
            {
                float t = Mathf.Clamp01(_e.Shield / _e.ShieldMax);
                _shFill.localScale = new Vector3(_w * t, 0.05f, 1f);
                _shFill.localPosition = new Vector3(-_w * (1f - t) * 0.5f, 0.14f, 0f);
            }
        }

        private void BuildHpBar()
        {
            var root = new GameObject("HpBar");
            root.transform.SetParent(transform, false);
            root.transform.localPosition = new Vector3(0f, _e.Kind == EntityKind.Building ? _topY + 0.9f : 2.7f, 0f);
            _hpRoot = root.transform;
            ViewAssets.DecoQuad(_bk, Vector3.zero, new Vector2(_w, _h), root.transform, "Back");
            _hpFill = ViewAssets.DecoQuad(_g, Vector3.zero, new Vector2(_w, _h), root.transform, "Fill").transform;
            _shFill = ViewAssets.DecoQuad(_sh, new Vector3(0f, 0.14f, 0f), new Vector2(_w, 0.05f), root.transform, "Shield").transform;
            _shFill.gameObject.SetActive(false);
        }

        private GameObject FinishMesh(List<Vector3> bv, List<int> bt, List<Vector3> gv, List<int> gt, Material[] mats, bool lean)
        {
            var mesh = ViewAssets.CreateMesh(new List<Vector3>[] { bv, gv }, new List<int>[] { bt, gt });

            if (lean) go.transform.localRotation = Quaternion.Euler(-10f, 0f, 0f);
            _mr = go.GetComponent<MeshRenderer>();
            return go;
        }

        private void BuildBuilding(BuildingId type)
```

```csharp
using System.Collections.Generic;
using IronCurtain.Sim;
using UnityEngine;

namespace IronCurtain.View
{
    public sealed class BoardView : MonoBehaviour
    {
        private SimCore _sim;
        private readonly Dictionary<int, EntityView> _views = new Dictionary<int, EntityView>();

        public static Vector3 WorldPos(SimVec2 p) { return new Vector3(p.X, 0f, 3f - p.Y); }
        public static Vector3 WorldPos(GridPos p) { return new Vector3(p.Col, 0f, 3f - p.Row); }

        public void Init(SimCore sim, Transform parent)
        {
            _sim = sim;
            BuildBoard();
            foreach (var kv in sim.Entities)
            {
                var e = kv.Value;
                if (e != null) CreateView(e);
            }
        }

        public EntityView GetView(int entityId)
        {
            EntityView v;
            return _views.TryGetValue(entityId, out v) ? v : null;
        }

        public void OnSimEvent(SimEvent ev)
        {
            switch (ev.Type)
            {
                case SimEventType.EntitySpawned:
                    var e = _sim.GetEntity(ev.SubjectId);
                    if (e != null) CreateView(e);
                    break;
                case SimEventType.EntityRemoved:
                    EntityView rv;
                    if (_views.TryGetValue(ev.SubjectId, out rv))
                    {
                        _views.Remove(ev.SubjectId);
                        if (rv != null && rv.gameObject != null) Destroy(rv.gameObject);
                    }
                    break;
                case SimEventType.DamageDealt:
                    var dv = GetView(ev.SubjectId);
                    if (dv != null) dv.FlashHit();
                    break;
                case SimEventType.EntityDied:
                    var dv2 = GetView(ev.SubjectId);
                    if (dv2 != null) dv2.SetDead();
                    break;
            }
        }

        public void TickViews()
        {
            Camera cam = Camera.main;
            float dt = Time.deltaTime;
            foreach (var kv in _views)
            {
                var v = kv.Value;
                if (v == null) continue;
                var e = _sim.GetEntity(kv.Key);
                if (e == null || e.State == EntityState.Dead) v.SetDead();
                v.Tick(dt, cam);
            }
        }

        private void CreateView(Entity e)
        {
            if (_views.ContainsKey(e.Id)) return;
            var go = new GameObject("Entity_" + e.Id);
            go.transform.SetParent(transform, false);
            var view = go.AddComponent<EntityView>();
            view.Bind(e, e.Side, e.Hero, e.Building);
            _views[e.Id] = view;
        }

        private void BuildBoard()
        {
            // 棋盘:6×255 全格合并为 1 个 Mesh,双 submesh 深浅两色
            var dv = new List<Vector3>(); var dt = new List<int>();
            var lv = new List<Vector3>(); var lt = new List<int>();
            for (int row = 0; row < LaneGrid.Rows; row++)
            {
                for (int col = 0; col < LaneGrid.Cols; col++)
                {
                    var v = ((row + col) & 1) == 0 ? dv : lv;
                    var t = ((row + col) & 1) == 0 ? dt : lt;
                    ViewAssets.AddBox(v, t, new Vector3(col + 0.5f, -0.05f, 2.5f - row), new Vector3(1f, 0.1f, 1f));
                }
            }
            var mesh = ViewAssets.CreateMesh(new List<Vector3>[] { dv, lv }, new List<int>[] { dt, lt });
            ViewAssets.AttachMesh("Board", transform, mesh, new Material[] {
                ViewAssets.Flat(new Color32(0x1c, 0x22, 0x2c, 0xff), 0.25f),
                ViewAssets.Flat(new Color32(0x30, 0x3a, 0x4a, 0xff), 0.25f) });

            // 废土延展面 + 碎块(固定种子)
            Material waste = ViewAssets.Flat(new Color32(0x0a, 0x0d, 0x12, 0xff), 0.1f);
            ViewAssets.DecoBox(waste, new Vector3(127.5f, -0.12f, 0f), new Vector3(274f, 0.1f, 34f), transform, "Wasteland");
            var rng = new System.Random(1234);
            for (int i = 0; i < 8; i++)
            {
                float x = 4f + (float)rng.NextDouble() * 248f;
                float z = (i & 1) == 0 ? 4.5f + (float)rng.NextDouble() * 3f : -4.5f - (float)rng.NextDouble() * 3f;
                ViewAssets.DecoBox(ViewAssets.Flat(new Color32(0x14, 0x16, 0x1c, 0xff)),
                    new Vector3(x, 0.1f, z), new Vector3(0.8f + i * 0.15f, 0.35f, 0.7f + i * 0.1f), transform, "Debris" + i);
            }

            // 边缘围栏:南北发光条,东西短墙
            Material rail = ViewAssets.Mat(new Color(0.02f, 0.02f, 0.02f), 0f, 0.9f, new Color(0.45f, 0.55f, 0.7f), 0.3f);
            ViewAssets.DecoBox(rail, new Vector3(127.5f, 0.06f, 3.25f), new Vector3(255f, 0.06f, 0.14f), transform, "Rail_N");
            ViewAssets.DecoBox(rail, new Vector3(127.5f, 0.06f, -3.25f), new Vector3(255f, 0.06f, 0.14f), transform, "Rail_S");
            Material wall = ViewAssets.Flat(new Color32(0x1a, 0x1e, 0x26, 0xff));

            // 中央标记:中立资源点列(127)暗金中线
            Material mid = ViewAssets.Mat(new Color(0.02f, 0.02f, 0.02f), 0f, 0.9f, new Color(0.8f, 0.62f, 0.25f), 0.6f);
```
