## 二、设计总纲(权威)
- 世界坐标映射:**col 0..29 → x = col*2 米;row 0/1/2 → z = (1-row)*2 米**(row1 在 z=0 中线)。棋盘总尺寸 x∈[0,58]、z∈[-2,2]。
- 风格:低模科幻废土 + 霓虹。地面深色、格间深浅交替;建筑棱角分明;单位模块化机甲;阵营标识光:蓝方青蓝(≈0.2,0.85,1)、红方红(≈1,0.3,0.3)、中立灰白。
- 渲染架构:GameBootstrap(场景唯一物体)Awake 时读配置 → MatchSetup 搭对局 → BoardView 建棋盘并订阅 Sim 事件(EntitySpawned/EntityRemoved)创建/销毁 EntityView → Update 按固定步长驱动 Sim.Step() 并让 BoardView 每帧同步插值。
- 所有表现层代码只读 Sim 状态,**绝不写 Sim 状态**(驱动、显示、订阅事件)。
- `SimBootstrapper.cs` 已弃用(不要引用、不要改);新场景挂 `GameBootstrap`。

## 四、现状

### 4.1 现有 View 文件(弃用,勿改)
`Assets/Scripts/View/SimBootstrapper.cs` 全文:
```csharp
using IronCurtain.Sim;
using UnityEngine;

namespace IronCurtain.View
{
    // View 层只做驱动与呈现,不持有任何模拟状态
    public sealed class SimBootstrapper : MonoBehaviour
    {
        public SimCore Sim { get; private set; }
        public bool Paused { get; set; }

        private double _accumulator;

        private void Awake()
        {
            Sim = new SimCore(new SimConfig(), new SeededRng(42));
            Debug.Log("SimCore ready");
        }

        private void Update()
        {
            if (Paused) return;
            // 累加器解耦渲染帧率,保证固定 10Hz 步进
            double interval = 1.0 / Sim.Config.TickRate;
            _accumulator += Time.deltaTime;
            while (_accumulator >= interval)
            {
                _accumulator -= interval;
                Sim.Step();
            }
        }

        private void OnDestroy()
        {
            Sim?.ClearEventListeners();
        }
    }
}
```

### 4.3 对局搭建规范(照此实现 MatchSetup.Build)
1. `AiSystem.Reset(); VisionSystem.Reset(); HexSystem.Reset(); SiegeSystem.Reset();`
2. `var sim = new SimCore(new SimConfig(), new SeededRng(42)); sim.Game = cfg;`
3. 建筑布设(全部 Row=1;单线布局,D8 拍板):
   - Blue:Base(1,0)、Barracks(1,3)、ResourcePoint(1,6)、Tower(1,9)
   - Neutral:ResourcePoint(1,15)
   - Red:Tower(1,21)、ResourcePoint(1,24)、Barracks(1,27)、Base(1,29)
4. 两座兵营(Blue/Red)各自:`barracks.Prod = new ProductionSet();`
5. AI 配置:blueTier 非空 → `AiSystem.Configure(sim, Side.Blue, blueTier.Value)`;redTier 非空 → `AiSystem.Configure(sim, Side.Red, redTier.Value)`。主对局调用方传 `(cfg, null, AiTier.Normal)`(玩家蓝方,红方普通 AI)。
6. 配置读取:`GameConfigParser.FromJson(Resources.Load<TextAsset>("gameconfig").text)`(在 GameBootstrap 中执行;Resources 目录已有 gameconfig.json)。
7. 参考(测试中已证明可用的搭建顺序,取自 AiTests.cs 的 SetUp):先 Reset → 建 SimCore → 赋 Game → SpawnBuilding 逐个 → 兵营赋 Prod → AI Configure。

### 4.4 渲染规格
- **地面**:30×3 棋盘格,每格 2m×2m 的扁平 Box(y=-0.05),行+列奇偶决定深浅两种深色(如 #1a1d24 与 #23272f);棋盘边缘一圈细长 Box 围栏(y=0.3)暗色;格顶面朝上。
- **相机**:GameBootstrap 创建:透视 Camera,初始固定机位——位置约 (11, 17, -22),朝向棋盘 x∈[0,24] 区域中心(row1 中线),俯角约 45°;`Camera.main` 不依赖场景默认相机,自行创建;clear flags SolidColor,背景深蓝黑 #05070d;近裁 0.3 远裁 200。
- **光照**:Directional Light(白,强度 0.85,绕 y 旋转约 30°、俯角 60°)+ `RenderSettings.ambientLight` 深灰(0.25 左右),让 emission 霓虹突出。
- **单位模型**(模块化机甲,总高约 1.6m,六形态可区分;所有部件为 primitive 组合,材质用 ViewAssets.Mat):
  - PanShi 磐石:宽躯干 Box + 身前大盾(竖长 Box)+ 双肩发光条
  - ZhenYue 镇岳:宽躯干 Box + 右手大锤(圆柱+锤头 Box 或双球)+ 背部发光条
  - DuanFeng 断峰:瘦高躯干 + 长矛(细长 Box 斜置)+ 矛尖发光
  - ZhuFeng 逐风:小躯干 + 尖锥骑枪(细 Box)+ 两侧小翼板,身形略前倾
  - ZhuiRi 坠日:瘦躯干 + 弓(弧形用 3 段细 Box 拼)+ 弓弦发光
  - XingLuo 星落:细躯干 + 顶部杖(细 Box+发光 Sphere 杖顶)
  - 通用:底部阵营光环(0.05 高发光扁平 Cylinder 或 Quad 圆片,直径约 1.6m,TeamMat 材质,emission 强);头部小 Sphere;主材质 TeamMat。
- **建筑模型**(单格 2m 占地,棱角分明;主材质 TeamMat + 霓虹发光条):
  - Base 大本营:三层递缩 Box 阶梯塔(总高约 3m)+ 顶部发光标识块
  - Barracks 兵营:长条 Box(1.2 高)+ 正面深色门洞 Box + 顶部细长霓虹条
  - ResourcePoint 资源点:矮 Box + 中央发光柱(细高 Box,emission 强,中性灰绿)
  - Tower 箭塔:细高柱(高约 2.5m)+ 顶部发光环(3-4 个小 Box 环绕发光 Sphere)
  - 中立建筑用灰白材质;`Rubbled=true` 显示废墟:整体压扁(scale y×0.35)+ 暗灰材质 + 无发光条(EntityView.SetRubbled 切换)。
- **血条**:每个 EntityView 头顶世界空间血条(单位在模型上方 0.7m,建筑在顶部上方 0.3m):背景深灰 Quad(0.9×0.09)+ 前景 Quad 按 Hp/MaxHp 缩放,颜色血量>50% 绿→≤50% 黄→≤25% 红;单位满血时隐藏,建筑常显;Quad 始终面向相机(billboard,在 TickViews 中更新)。建筑加护盾时(Shield>0)前景上方叠一条浅蓝细条(Shield/ShieldMax)。
- **平滑同步**:EntityView.Bind 记录实体引用;TickViews 中:目标世界坐标 = Pos 映射(x=col*2, z=(1-row)*2, y 单位 0.9/建筑 0);`transform.position = Vector3.Lerp(transform.position, target, 1 - Mathf.Exp(-14f * Time.deltaTime))`;朝向:按实体 Side(Blue 面朝 +x、Red 面朝 -x,即模型正面朝向敌方);单位 State==Dead 或实体已移除 → SetDead(播放简单缩隐后由 BoardView 在 EntityRemoved 事件里 Destroy)。
- **事件接线**(BoardView):监听 `EntitySpawned` → GetEntity 后创建 EntityView 并 Bind;`EntityRemoved` → 销毁对应视图;`DamageDealt` → 预留调用 `view.FlashHit()`(M6.4 模块将实现,本模块在 EntityView 留一个公开空方法 FlashHit() 即可,不实现特效);`EntityDied` → 对应视图 SetDead(等待随后的 EntityRemoved 销毁)。
- **视图生命周期**:BoardView.Init 时先按 sim.Entities 现有实体创建全部视图;对局中实体生成/销毁全部走事件。GameBootstrap.OnDestroy → `sim.ClearEventListeners()`。

### 4.5 GameBootstrap 细节
- Awake:读配置 → `Sim = MatchSetup.Build(cfg, null, AiTier.Normal)` → 创建相机/光照 → `Board = new GameObject("Board").AddComponent<BoardView>(); Board.Init(Sim, transform);` → `AddEventListener` 转发给 Board。
- Update:`if (Paused) return;` 累加器:`interval = 1.0 / Sim.Config.TickRate; _accumulator += Time.deltaTime * Speed; while (_accumulator >= interval) { _accumulator -= interval; Sim.Step(); }`(Speed 默认 1,公开可调);随后 `Board.TickViews()`。
- 公开字段:`public SimCore Sim; public BoardView Board; public Camera Cam; public bool Paused; public float Speed = 1f;`
