# M5.0 视野与战争迷雾 —— VisionSystem(GL M 绿场实现+测试)

## 一、角色与任务
你是《铁幕:前线》Unity 6 项目视野系统主程。本模块实现**双方对称的视野/迷雾信息层**(纯信息,不影响战斗)。只新增两个文件:`Assets/Scripts/Sim/VisionSystem.cs` 与 `Assets/Tests/EditMode/VisionTests.cs`。**禁止修改任何既有文件**(112 个既有测试必须保持全绿)。编排者已把 `VisionSystem.Tick(this, dt)` 挂进 SimCore.Step 末尾。

## 二、规则(权威,详见 docs/视野与迷雾规格.md,D34/D35)

- 视野来源(曼哈顿半径):近战单位(磐石/镇岳/断峰/逐风)6 格;射手(坠日/星落)9 格;断峰·鹰眼 10 格(条件:朝向敌方向无其他己方**野战**单位——即该断峰是己方最靠前的野战单位);箭塔 12 格;大本营 20 格;其他建筑(兵营/资源点)10 格。
- 视野精灵:每 30 秒(300 tick)从己方大本营出发(0/300/600…),速度 10 格/s(每 tick 1 格)沿单线朝敌方大本营推进,30 tick 扫完;扫掠时揭示其所在**列的全部 3 排**;不可被攻击、不占格。
- 时效:任何来源揭示的信息**新鲜 3 秒(30 tick)**;过期后:据点冻结在最后时刻(血量/驻军数/归属/废墟态),露天军队直接消失。
- 驻军信息:揭示敌据点只知**驻军人数**(正式+临时合计),不知构成。
- 对称:每方维护自己的视野;玩家与 AI 同源。纯信息层,不影响任何战斗/移动/索敌判定。

## 四、接口契约(严格实现)

### VisionSystem.cs(`namespace IronCurtain.Sim`,静态类)
```csharp
public static void Reset();   // 清空全部状态(测试用)
public static void Tick(SimCore sim, float dt);
// 每 tick 按序更新每方视野(蓝红各一):
// 1) 单位来源:野战单位(State!=Dead、GarrisonBuildingId==0)以其 Pos 为中心标记半径内格子"本 tick 可见"
//    半径:Range>1 → 9;Hero==DuanFeng 且鹰眼条件成立 → 10;其余 → 6
//    鹰眼条件:己方(GarrisonBuildingId==0、State!=Dead/Exchanging)中不存在"更靠敌方向"的野战单位
//    (朝敌方向:蓝=Col 更大,红=Col 更小;即该断峰 Col 为全队最靠前)
// 2) 建筑来源:非废墟建筑按类型半径标记(塔 12/大本营 20/其他 10);堡垒(IsFort)按 10
// 3) 精灵:记录每方下一次出发 tick;到点后持续 30 tick,每 tick 精灵列 = 大本营列向敌方推进 1 格,
//    标记该列全部 3 排"本 tick 可见";精灵不产生实体
// 4) 数据存储(每方):Dictionary<long cellKey, long lastSeenTick> 与
//    Dictionary<int buildingId, BuildingSnapshot>;BuildingSnapshot 字段:Hp/MaxHp/Side/Rubbled/GarrisonCount
//    本 tick 该建筑所在格被揭示 → 更新其快照(Hp/驻军人数=Formal+Temp/Side/Rubbled)
// 内部常量:FreshTicks=30;SpriteIntervalTicks=300;SpriteSpeedCellsPerTick=1
public static bool IsFresh(SimCore sim, Side side, GridPos cell);
// 该格 lastSeenTick 满足 Tick - lastSeen <= FreshTicks
public static bool IsUnitVisible(SimCore sim, Side side, int unitId);
// 单位存在且其所在格 IsFresh(驻军单位:以其建筑格判断)
public static bool IsBuildingKnown(SimCore sim, Side side, int buildingId); // 有快照即可(冻结也算)
public static int? LastKnownGarrison(SimCore sim, Side side, int buildingId); // 无快照→null
public static float? LastKnownHp(SimCore sim, Side side, int buildingId);     // 无快照→null
```

### VisionTests.cs(EditMode,[Test] 8 个)
SetUp 照抄既有模板(static _cfg + sim + sim.Game);每测试自建所需建筑。坐标一律(行,列)。
1. 单位视野半径:蓝近战(磐石)在 (1,5),红断峰放 (1,5+6)= (1,11)(曼哈顿 6)→ IsUnitVisible(红)==true;(1,12)(7 格)→ false;蓝射手(坠日)放 (1,5),红断峰在 (1,14)(9 格)→ true,(1,15)→ false
2. 建筑视野:蓝塔 (1,6),红断峰 (1,18)(12 格)→ true,(1,19)→ false;蓝大本营 (1,0),红断峰 (1,20)(20 格)→ true
3. 鹰眼:蓝断峰 (1,10)、蓝磐石 (1,12)(磐石更靠前,Col 更大)→ 断峰视野 6:红单位 (1,16) 不可见;移除磐石后 tick → 鹰眼激活,红单位 (1,19)(9 格)可见
4. 精灵扫掠:蓝大本营 (1,0)、红塔 (1,25) 红驻军 3(直接 Add id 到 GarrisonFormal+设 GarrisonBuildingId);tick 0 精灵出发,3 秒内扫过 → IsBuildingKnown(蓝,红塔)==true 且 LastKnownGarrison==3
5. 信息 3 秒过期:蓝近战 (1,5) 与红近战 (1,8) 相邻可见;把红近战 SetMoveTarget 到 (1,28) 并跑 40 tick → IsUnitVisible(蓝,红)==false(走出视野且超 3 秒)
6. 据点冻结:蓝塔 (1,6) 被红单位在 (1,8) 看到(近战 6 格:距离 2 ✓);红单位离开 50 tick 后 → IsBuildingKnown==true(冻结)且 LastKnownHp==50(旧值);然后蓝塔被拆到 40 血(Hp 直改)→ LastKnownHp 仍==50(冻结值不变)
7. 对称性:蓝近战 (1,5),红近战 (1,15)(相距 10,互不可见)→ IsUnitVisible(红看蓝)==false 且 IsUnitVisible(蓝看红)==false;各自看自己 ==true
8. 露天军队消失无冻结:红近战经过蓝视野后离开 → IsUnitVisible false 且无任何"单位快照"机制(断言 IsBuildingKnown 不适用单位——用 IsUnitVisible false + 视野外 LastKnown 类接口返回 null 语义即可,单位无快照)
