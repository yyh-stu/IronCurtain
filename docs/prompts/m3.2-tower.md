# M3.2 箭塔战斗 —— 自动攻击/溅射/驻军强化(GL M 绿场实现+测试)

## 一、角色与任务
你是《铁幕:前线》Unity 6 项目战斗系统主程。本模块实现**箭塔自动战斗**:2.5 秒间隔、射程 5 格、单伤 18、溅射 12(半径 1 格)、驻军强化(每人 +2 攻击封顶 +12,满 9 人溅射半径 +1)。只新增两个文件:`Assets/Scripts/Sim/TowerCombatSystem.cs` 与 `Assets/Tests/EditMode/TowerCombatTests.cs`。**禁止修改任何既有文件**(62 个既有测试必须保持全绿)。

## 二、规则(权威)
- GDD 2.3:箭塔 血量50 攻击18(溅射12) 攻击间隔2.5秒 射程5格 可驻军强化。
- D3(已拍板):驻军每 1 人攻击 +2(上限 +12);满 9 人时溅射范围 +1 格。
- D25(编排拍板):溅射半径=1 格(即目标周围曼哈顿距离≤1 的格)。
- 箭塔算"远程"攻击源:命中镇岳受 0.7 修正、命中逐风受 1.25 修正、命中磐石受非破防 70% 减伤——统一走既有 `DamageCalculator.CalculateDamage(attacker=塔, defender=目标, cfg, isCharge=false)`。
- 箭塔不攻击建筑、不攻击城内/驻军单位(GarrisonBuildingId!=0 或 State==Exchanging 的目标跳过)。

## 四、接口契约(严格实现)

### TowerCombatSystem.cs(`namespace IronCurtain.Sim`,静态类)
```csharp
public static class TowerCombatSystem
{
    public static void Tick(SimCore sim, float dt);
    // 遍历所有箭塔(Kind==Building && Building==Tower):
    //   冷却递减:AttackCooldown -= dt(与单位共用同一字段)
    //   冷却<=0 时索敌:射程(Range)内最近的敌军单位(Manhattan,平局取小 id);
    //     目标条件:Kind==Unit、Side!=塔.Side、State!=Dead、GarrisonBuildingId==0、State!=Exchanging
    //   命中:伤害 = Attack(18) + min(AttackBonusCap, GarrisonFormal.Count × AttackPerGarrison)
    //     将加成写入临时本地 attack(不改实体 Attack 字段,免得污染单位通用属性)
    //     主目标:CalculateDamage(塔实体, 目标, cfg, false),先扣护盾再扣血(逻辑照抄 SimCore.ApplyAttack 的护盾顺序)
    //     溅射:半径 = SplashRange(1) + (GarrisonFormal.Count>=9 ? SplashRangeBonus : 0);
    //       对半径内其余敌军单位(不含主目标)各结算 SplashDamage(12) 走同一 CalculateDamage(塔, 单位, cfg, false)→护盾→血
    //     攻击后 AttackCooldown = AttackIntervalSec(2.5)
    //   射程内无目标 → 冷却清 0(不空转等待)
    // 死亡处理:被塔打死的单位 State=Dead(本模块只标记,不做 RemoveEntity/事件——由编排者下一轮统一收口)
}
```
### TowerCombatTests.cs(EditMode,[Test] 8 个)
SetUp 加载 gameconfig(照抄既有模式)。塔位置 (1,6) 蓝方;目标放 (1,11)(距离 5)等。
1. 射程内开火:蓝塔 vs 红磐石(距离 5,HP80 盾140):25 tick 首炮 → 磐石盾 140-12.6(18×0.7)≈127.4;第 2 炮在 50 tick
2. 射程外不开火:目标距离 6 → 100 tick 无伤
3. 溅射:主目标 (1,10),副目标 (0,10) 距离主目标 1 → 主目标 18(无修正目标,选断峰),副目标 12;溅射不伤害塔方单位(放一蓝方单位在 (1,9) 半径内 → 不受伤)
4. 驻军强化:蓝塔 GarrisonFormal 放 3 只(直接 Add id+设 GarrisonBuildingId,无需真实单位实体)→ 主伤 = 18+6=24
5. 强化封顶:GarrisonFormal 放 9 只 → 主伤 = 18+12=30(而非 36)
6. 满员溅射+1:GarrisonFormal 9 只,副目标距主目标 2 格 → 仍受溅射;不足 9 时距 2 格不受
7. 镇岳修正:目标镇岳(距离5)→ 每炮 18×0.8×0.7=10.08(断言伤害值用血量差,容差 0.01)
8. 不攻击驻军单位:红方单位设 GarrisonBuildingId=红塔(非零)→ 蓝塔对其不开火;不攻击 Exchanging 单位
