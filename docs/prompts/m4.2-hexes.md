# M4.2 海克斯系统 + 道具 —— 8 卡/抽取/堡垒/攻城锥/临时阵地(GL M 绿场实现+测试)

## 一、角色与任务
你是《铁幕:前线》Unity 6 项目海克斯系统主程。本模块实现完整海克斯闭环。只新增两个文件:`Assets/Scripts/Sim/HexSystem.cs` 与 `Assets/Tests/EditMode/HexTests.cs`。**禁止修改任何既有文件**(102 个既有测试必须保持全绿)。编排者已挂好全部钩子(见三)。

## 二、规则(权威,GDD + 拍板)
- 抽取:对局 3 分钟后解锁;节点 3/5/7/9 分钟(即 tick 1800/3000/4200/5400);每次随机三张、三选一;单次三选不重复;抽取消耗 2EP;卡可存手牌任意释放——**demo 简化:抽取后立即三选一激活,不做手牌存储**。
- 同阵营同时只生效一张,新卡覆盖旧卡(旧卡剩余时间清空);全图可见特效(表现层,本模块不管)。
- 已用卡后续权重 -50%(D4:胜率动态不做)。
- D28 伤害叠算公式:增益加算、免伤乘算(见下)。
- D29:曲径通幽只做"不锁塔",穿行不做。
- D31:钢铁洪流=生命≥100 的单位(镇岳)移速+50% 且免疫负面;激活后前 30 tick(3 秒)全场友军承伤×0.5。
- D32:堡垒(铁壁防线/临时阵地)驻军上限 3。
- D33:临时阵地可放任意空闲线格。

## 四、接口契约(严格实现)

### HexSystem.cs(`namespace IronCurtain.Sim`,静态类)
```csharp
static HexId? ActiveOf(Side side);           // 当前生效卡
static float ActiveRemainingOf(Side side);   // 剩余秒
static void Reset();                          // 清空全部状态(测试用)

static bool CanDraw(SimCore sim, Side side);  // 已解锁(tick≥1800)且当前 tick 处于节点窗口(节点后 100 tick 内)且 EP≥2
static List<HexId> DrawChoices(SimCore sim, Side side);
// 用 sim.Rng 抽取:候选池 = 全部 8 卡,按权重(已用卡 ×0.5);三张互不重复;必须确定性(同种子同结果)
static bool UseHex(SimCore sim, Side side, HexId card, int targetUnitId, out string error);
// 校验:EP≥2(扣 2);targetUnitId:仅沙包必须(目标=己方单位,否则 error"目标无效");其余卡忽略该参数
// 激活:覆盖旧卡(清旧剩余与旧卡效果状态);记录激活时间与时长(config DurationSeconds);
//  卡片效果初始化:IronWall → 立即生成堡垒;Sandbag → 对目标单位记录 buff(30s)
static void Tick(SimCore sim, float dt);
// 1) 激活卡计时:剩余 -= dt;到期 → 清 Active 并回收效果:
//    IronWall 到期:堡垒移除(移除前把其驻军放出:单位 GarrisonBuildingId=0、State=Idle、Pos=堡垒旁空闲格)
// 2) 效果实时结算(按 Active 卡与激活时长):
//    SteelTide:前 30 tick 内 DamageReductionOf(该方所有单位)=0.5;期间该方生命≥100 单位 MoveMultiplierOf=1.5;该方单位 DebuffImmune=true
//    RapidDeploy:ProductionSecondsMultiplier(该方)=1/1.4;PopCapBonusOf(该方)=+20% 人口上限(SimCore.PopulationCapOf 已含此调用,直接用其返回值的 20% 由你提供)
//    Vengeance:层数栈(每层 +0.05 输出、-0.05 承伤、移速 ×(1+0.05×层),单层 15s 后过期);OnUnitDied 时入栈
//    LightMobility:该方单位在"己方任意建筑 10 格内"时 MoveMultiplierOf ×2
//    IronWall:堡垒每 3 秒对曼哈顿≤2 的敌单位造成 15 伤害(护盾先扣再血;死亡走 State=Dead 标记即可,不 RemoveEntity)
//    HoldFast:该方单位在"己方任意建筑 10 格内"时 OutputBonusOf +0.10、DamageTakenBonusOf -0.10、MoveMultiplierOf ×1.1
//    HiddenPath:TowerExempt(该方)=true
//    Sandbag:目标单位 DamageReductionOf ×0.5、OutputBonusOf -0.5
static bool UseRam(SimCore sim, Side side, int buildingId, out string error);
// 1EP;目标=敌方建筑(Rubbled 或 Neutral 拒绝,error 含"目标");DestroySystem.ApplyBuildingDamage(sim, b, RamDamage, side)
static bool UseFort(SimCore sim, Side side, GridPos cell, out string error);
// 1EP;cell 必须空闲(无实体占用)→ 生成堡垒:SpawnEntity(side, Building, cell) + IsFort=true + Hp=MaxHp=30;登记 30s 到期
```

### HexTests.cs(EditMode,[Test] 10 个)
SetUp 照抄既有模板(static _cfg + sim + sim.Game)。坐标一律 (行,列)。
1. 节点解锁:1800 tick 前 CanDraw==false;tick 1800~1900 内 CanDraw==true(EP 足够时)
2. 三选一不重复:DrawChoices 三张互不相同且均合法;同种子两次结果一致
3. 激活覆盖:先 UseHex(SteelTide) 再 UseHex(HiddenPath) → ActiveOf==HiddenPath,SteelTide 效果消失(TowerExempt 由 false 变 true)
4. 钢铁洪流:镇岳(200血)激活期间移速 ×1.5(10 tick 位移 3 格);磐石(80血)移速不变;该方单位免疫负面(ApplyOnHitEffects 施加沉默无效)
5. 快速部署:生产时间 ×1/1.4:磐石原 60 tick → 43 tick 出(断言 60/1.4≈42.9,容差 2 tick);人口上限 +20%
6. 陷阵之志:激活后友军阵亡 1 只 → 友军输出 +5%(打桩:友军磐石攻击断峰 6×1.05=6.3);阵亡 2 只 → +10%(6.6)
7. 铁壁防线:激活生成 30 血堡垒;敌单位进 2 格内每 3 秒受 15;30s 后堡垒消失且驻军离城 Idle
8. 以逸待劳:己方建筑 10 格内友军攻击 +10%(磐石 6→6.6)、承伤 -10%;10 格外友军不受影响
9. 沙包:目标己方单位承伤 ×0.5(磐石挨 6 打只掉 6×0.7(盾)×0.5…… 用断峰目标:承受 6 打 → 3)、输出 ×0.5(目标反击 14→7)
10. 道具:UseRam 敌方建筑 15 直伤(50→35);再放三枚 → 5 → 下一枚废墟化(Rubbled==true、守军后撤);UseFort 空闲格生成 30 血堡垒、占用格报错
