## 二、地形规格(权威,照此实现)

- **坐标空间**:矩形包围盒 **Row 0..29(共 30)、Col 0..285(共 286)**;格 (row,col) 中心连续坐标 = `SimVec2(col+0.5, row+0.5)`(X=列米,Y=行米)。
- **椭圆**:中心 (143,15),长半轴 143(X),短半轴 15(Y)。`IsInside(v)`:((X−143)/143)²+((Y−15)/15)² ≤ 1。**单位不可越出椭圆**。
- **河(楚河汉界)**:X∈[138,148)(10 格宽,Y 全高);**水域=河段且非桥**。
- **桥(上下各一座,5 格宽)**:上方桥 X∈[138,148) 且 Y∈[25,30);下方桥 X∈[138,148) 且 Y∈[0,5)。**桥上正常速度**;涉水(水域)移动速度 ×0.5。
- **中立资源点**:河中央小岛 X∈[139,147) 且 Y∈[11,19) 视为陆地(即河中央一块 8×8 陆地岛;岛上格既非水域也非桥,正常速度)。
- **建筑布局(间距 30,全在长轴 Row=15)**:
  | 建筑 | 蓝Base | 蓝兵营 | 蓝资源点 | 蓝箭塔 | 中立资源点 | 红箭塔 | 红资源点 | 红兵营 | 红Base |
  |---|---|---|---|---|---|---|---|---|---|
  | Col | 15 | 46 | 77 | 108 | 143(岛) | 178 | 209 | 240 | 271 |
- **集结点**:蓝 (15,270)、红 (15,16)(敌方大本营前 1 格)。
- **TerrainMap 接口**(静态类,新增):
  ```csharp
  public static class TerrainMap
  {
      public const int Rows = 30;
      public const int Cols = 286;
      public static bool IsInside(SimVec2 v);        // 椭圆内(含边界)
      public static bool IsInside(GridPos p);        // 格中心在椭圆内
      public static bool IsWater(SimVec2 v);         // 水域(非桥、非中央岛)
      public static bool IsBridge(SimVec2 v);        // 桥
      public static float MoveFactor(SimVec2 v);     // 桥上/陆地=1;水域=0.5
      public static SimVec2 ClampToEllipse(SimVec2 v); // 把 v 推回椭圆(径向投影到边界)
  }
  ```

## 三、各文件改动契约

### 3.1 LaneGrid.cs / SimConfig.cs
- `LaneGrid.Rows=30`、`Cols=286`;SimConfig 默认参数同步(30,286)。GridPos 的 IsValid 随之自动适用矩形包围盒(不变)。

### 3.2 SimCore.cs
1. `_rally` 默认值改为 `{Blue,(15,270)}, {Red,(15,16)}`。
2. `MoveUnits`:每单位移动完成后 `e.PosF = TerrainMap.ClampToEllipse(e.PosF)`(在 PushOutOfBuildings 之后)。
3. `MoveSpeedOf`:最后乘 `TerrainMap.MoveFactor(e.PosF)`(涉水减半,桥上正常)。
4. `SoftCollide` 后同样 ClampToEllipse(推挤可能把单位挤出椭圆)。
5. 其余(索敌/攻击/伤害公式)不动。

### 3.3 VisionSystem.cs
- `Rows/Cols` 常量改用 LaneGrid 值(30/286)。
- `MarkDisc`:圆盘标记时跳过椭圆外格(用 TerrainMap.IsInside(new GridPos(row,col)) 过滤)。
- 精灵扫掠:列 0..285 照旧(飞越河面,无地形限制);揭示该列时同样只记椭圆内格。
- `Key(GridPos)`:Row*1000L+Col 保留(Col≤285 安全)。

### 3.4 AiSystem.cs
- `FrontCell(sim, Entity b)`:城门点=建筑中心+朝敌方向×(碰撞半径+0.6);行序优先 15,然后 14/16/13/17…(即 `new[]{0,-1,1,-2,2,-3,3}` 相对 Row=15);候选格须 TerrainMap.IsInside 且非水域。
- `Home(sim, side)` 兜底坐标:蓝 (15,15)、红 (15,271)。
- 其余决策逻辑不动。

### 3.5 GarrisonSystem.cs
- `FindGateCell`:与 AiSystem.FrontCell 同规则(行序 15 优先、椭圆内、非水域、向外延展 4 列)。
- `RallyPointOf(side)`:蓝 (15,270)、红 (15,16)。
- 出击/射击/溃逃逻辑不动(溃逃目的地搜索照旧)。

### 3.6 SiegeSystem.cs
- `FrontCell(sim, unit, b)`:与 3.4 同规则(城门点格+椭圆/水域过滤)。
- 交换/封城/占领逻辑不动。

### 3.7 ProductionSystem.cs
- `SpawnOffsets`:出生点=兵营前方 4 格(碰撞半径避让),行偏移 `{0,-1,1}`(相对兵营行);候选格须椭圆内且非水域。
- 其余不动。

### 3.8 MatchSetup.cs(View 层布局)
- 按上表新坐标搭建 9 座建筑(全部 Row=15);兵营赋 ProductionSet;AI 配置不变(红 Normal)。

### 3.9 TerrainTests.cs(新增测试,照项目测试模板:SetUp 加载 gameconfig、静态 _cfg 缓存)
断言至少覆盖:
1. 椭圆中心/长轴端点/短轴端点在椭圆内;X=0(左端外)与 X=285(右端外)不在。
2. 河心(143,15 附近非岛处)IsWater=true 且 MoveFactor=0.5;中央岛 IsWater=false。
3. 上方桥(140,27)IsBridge=true、MoveFactor=1;下方桥(140,2)同样。
4. ClampToEllipse:把 (143,50) 推回后 IsInside=true。
5. 移动涉水减速:两个 SimCore,一个单位目标在河对岸(走桥路线上下绕行不可行时,用 SetMoveTarget 到河对岸同 Y 让单位直穿河):单位 MoveSpeed=2,在河水中跑 10 tick 位移≈1 格(而非 2 格)——用 TerrainMap.MoveFactor 单测代替即可,移动集成断言留一条"涉水单位速度减半"(位置对比)。
6. 椭圆边界:单位 SetMoveTarget 到椭圆外格(15,5)→ 移动后 PosF 仍在椭圆内。
