## 0. 攻城指令规则(2026-09-04 用户拍板,M3 契约核心)

### 0.1 意图存建筑,不存军队(优雅实现,用户认可方向)
- 每座建筑持有按进攻方区分的 **SiegeIntent**(None/Capture/Destroy);玩家指令=写该字段+给框选军队下达移动指令。
- 军队到达后读建筑当前 intent 执行;**后写覆盖先写,同据点对同方任意时刻只有一种指示状态**。
- 普通 AI 与玩家共用同一接口(设 intent + 派兵)。

### 0.2 选项面板(按建筑归属确定,无歧义)
- 己方据点 → 仅"驻军";敌方据点 → "摧毁/占领"双选;中立据点 → 仅"占领"(无血量,摧毁无意义);敌方大本营 → 仅"摧毁"(不可易主,摧毁即胜)。

### 0.3 封城与切换锁(用户拍板)
- 交换(占领)进行中即封城:守方不可入城,攻方可增援进城继续交换。
- **封城期间意图锁死,不可切换**;封城结束(城内交换分出胜负)后才允许切换。
- 摧毁模式无封城,攻占/摧毁间切换在无封城时任意时刻允许。

### 0.4 占领成功后
- 幸存入城部队**自动转为正式驻军**(上限 9,超出者离城待命)。符合"驻军只存在于己方地盘"。

### 0.5 目标完成后
- 参与进攻的部队**原地待命**,等待玩家下一道指令。

### 0.6 交互形式
- 支持**点选**(单只)与**框选**(多只),超 GDD 10.1,记为规格升级。

### 0.7 驻军详情与撤出(2026-09-04 用户拍板,D24)
- 有驻军的建筑可点击查看**驻军详情面板**:按兵种分组显示数量(如磐石×3、坠日×2),正式/临时分两区展示。
- 每行提供"撤出"按钮:**每次点击释放该兵种一只**,到城门站定(State=Idle 原地待命,可再受指令)。
- 城门位置 = 建筑朝敌一侧的邻格(复用攻城 FrontCell 逻辑,全占则本侧向外延展)。
- Sim 契约(M3.3 实现):`GarrisonSystem.Exit(sim, buildingId, HeroId, out error)`——从指定分区(正式优先)释放该兵种一只;临时驻军同样可撤出(撤出即不再计时)。

## 1. 镜头系统(新增规格,归属阶段 6 表现层)

**1.1 边缘滑动**
- 鼠标指针停留在屏幕边缘(建议默认热区 40px)时,镜头沿该方向**匀速平移**;指针离开边缘即停止。
- 速度要求"肉眼可反应"(移动效果可见、可预判),首版**不做惯性/缓动**,保持匀速。

**1.2 速度可调(接口先行,设置 UI 后置)**
- 镜头平移速度抽为**公开可配置参数**(编辑器可调/配置项),默认值由调参决定。
- 玩家设置面板**后置**:本次 demo 不做设置界面,只保证参数可调、后续接 UI 即可。

**1.3 单线视野假设(实现层确认)**
- demo 为单线(3×30),镜头默认视野宽度**小于整条线**,需要横向平移才能看全;
- 纵向 3 排尽量整屏可见;具体视口比例/默认缩放由实现层自行发挥。

## 2. 全局小地图

**2.1 形态**
- 常驻界面角落(建议右上),显示**整条战线**缩略图:建筑与单位位置、阵营色标识。
- 单线 demo 中呈**长条缩略图**(对应 3×30 线)。

**2.2 点击跳转**
- 鼠标在小地图上**点击 = 镜头切换到该局部**(点击横向位置映射为镜头目标)。
- 拖动小地图平移:实现层自发挥项,默认**只做点击**,可加可不加。

## 3. 操作 UI 原则(简明直观、点击驱动)

**3.1 图标即行为,点击即指令**
- 以兵营生产为例(已拍板):生产面板直接放**该角色头像按钮**,点击头像 = 生产该角色(入队规则仍按 GDD:队尾追加、仅队尾可取消、人口校验、取消返还人口)。
- 禁止多级菜单、拖拽、右键弹窗等繁琐路径;一切主操作单次点击完成。

**3.2 其余交互自行发挥 + 人工检查门**
- 选中、移动/驻扎/进攻指令、海克斯抽取与释放、升级、道具使用等,由实现层按"简明直观、点击驱动"原则自行发挥;
- **交付后由用户试玩检查,不符合预期即提修改意见**,迭代至用户认可。
