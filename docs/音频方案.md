# 音频方案（待制作人拍板,未实施）

> 2026-09-10 无人值守时段整理。音频从未做过,本文只出方案;拍板后按分期实施。

## 1. 架构原则（与现有工程对齐）

1. **Sim 层零 UnityEngine（硬门禁不变）**：音频纯 View 侧,由 SimEvent 事件流驱动——与 BeamFx/飘字/烟雾同款管线,事件同帧触发,天然音画同步。
2. **AudioSystem 单例 + AudioSource 对象池**（8-12 源,按优先级抢占,低优先级让位）;AudioMixer 分组 Master/SFX/UI/BGM,音量设置持久化。
3. **事件→音效映射表**数据驱动（同 InputAudit 风格）,加音量/优先级/随机 pitch（防重复感）。

## 3. 音源路线（可混合,推荐 A+C）

- **A. CC0 免费音效库（主力,¥0）**：Kenney 官方音效包（与现用 Kenney 过渡美术同源,风格兼容性最稳）、freesound CC0 筛选。快、免费、风险低;独特性一般。
- **B. AI 音效生成（暂缓）**：TokenHub 平台音频类模型可用性未查证（需 `tokenhub.py models audio` 探一次）;可定制卡通风格化音色,但按量计费+质量不稳。等 A 验收后有明确缺口再启用。
- **C. 程序化合成（少量 UI 音）**：EP 滴答、UI blip 等简单音代码合成,零资产零成本。

## 4. BGM（2026-09-10 制作人定方向:参考《决战！平安京》两阶段切换）

**制作人拍板**:推掉或占领敌方第一个建筑前一首 BGM,之后换一首;前期偏轻松、后期偏激烈,但**不密集、不干扰玩家操作体验**。

**决战平安京风格参考**(已检索):和风基调——三味线/筝/尺八/太鼓等日式乐器+现代管弦;对线期舒缓静谧带一丝诡谲,战局推进后节奏加密、太鼓弦乐推进感增强;作曲梅林茂(阴阳师系)。曲目气质参考《平安百鬼譚》《開戦》《雲隠れ》。

**两阶段设计**:
- **前期曲「对线」**:和风小调,筝+三味线主题+轻尺八,节奏舒缓(BPM≈70-90),音量克制,可长时间循环不觉吵。
- **后期曲「决战」**:同调性同主题变奏,太鼓节奏加强+弦乐推进(BPM≈100-120),激昂但配器留白,不让打击乐铺满(不密集原则)。
- **切换触发**:Sim 事件驱动——敌方建筑首次被摧毁(Rubbled)或首次易主(Side 变更,排除开局中立)时切换;**交叉淡入淡出 2-3 秒**,不硬切;切换一次性,不回切(后期曲保持到终局)。结算画面另用胜利/失败短乐收尾。
- **实现**:View 侧 BgmController(双 AudioSource 交叉淡化),监听既有 SimEvent 流,零 Sim 改动。

**音源路线**(更新):免费库难找"梅林茂式和风"高匹配曲;TokenHub 已查有 **minimax-music-v3.0**(音乐生成,价格待核)——推荐 AI 定制生成两首(风格描述精确可控、可迭代重生成);备选免费库+人工筛选。生成属按量计费,遵守 14:00-18:00 峰值禁令。
