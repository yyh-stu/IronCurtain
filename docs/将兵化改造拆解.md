# 将兵化改造 · 需求拆解(用户拍板 2026-09-05,已开工)

> 权威规格 = PROJECT_STATE.md「已批准的设计变更」#9。本文为任务拆解与分发顺序。
> 大原则:士兵=轻量 Unit 实体,现有 Sim(移动/战斗/驻军/交换/视野)尽量复用,不做推倒重写。

## 0. 终版规格速查(与 PROJECT_STATE #9 同步)

- **兵团**:1 将 + 20 兵,兵随将走(阵型跟随),红警式可调遣;将上限:正式 8、测试版 4(开局赠 3:磐石/断峰/坠日);将战死=退役、名额释放可再产;将死后士兵**永不溃逃,无将状态就近逐杀至死**。
- **士兵属性**:盾/血/攻 = 将的 1/10;攻速、移速 = 将;**视野:近战 3、远程 6**(坠日/星落=远程,其余近战);士兵无血条,兵团在将血条旁显示"兵力 X/20"。
- **将生产**:主基地产将,20s/将,出场自带满编 20 兵;测试期六将均可产(无选将/BP,另立模块)。
- **兵营**:只承担补兵(池生产);**补兵池**:全局 2s/兵、上限 60(平拍);点补兵按钮→全局 SJF(最缺人兵团先补,补齐为止)→入队前完成变装为该将兵种装束;交战兵团不可补、脱战 3s 入列;demo 行军补兵不可被截击(纯表现,士兵从生产点走出)。
- **攻城交换**:只消耗兵,将不参与(留城外);封城下临时驻军城后等候、不参与交换、不进正式驻军;城易主→自动溃逃;城守住→恢复临时并补入正式;**等候部队保持可调遣,玩家可主动拉去截击敌方增援**(调遣即截击,无新机制)。
- **驻军容量(默认)**:正式 30 兵/城、临时 30;交换 1:1 兵/次,节奏沿用现 Siege 参数。
- **建筑多格占用**(推翻早期"逻辑单格"):按视觉占地,尺寸配置化,初值:基地 5×5 / 箭塔 4×4 / 兵营 5×4 / 资源点 4×4 / 堡垒 3×3(中心锚定,建议奇数格)。
- **人口**:废除英雄人口,改为**将名额制**(测试版 4)。士兵不占人口。

## 2. 美术并行线(独立于 Sim,红线:生图→人工复核→3D)

1. **风格定稿**:生图模型出 3~4 张候选(地形小样+英雄造型+建筑造型)→ 用户挑 → 风格文档。
2. **六将 3D**:每将生图(风格锚定)→ 用户复核 → hy-3d-3.0 → 导入替换 Kenney。
3. **六兵种 3D**:每将专属士兵简单建模(同上流程;简而次之,不喧宾夺主)。
4. **建筑 4 类 3D**:基地/兵营/箭塔/资源点(定稿后按真实剪影更新 BuildingFootprint 尺寸)。
5. 动画(hy-3d-motion)待验证,后置。
