# 城墙美术方案（DeepSeek，2026-09-11 评估制作人提案）

> 制作人提案：**利用箭塔拼成城墙，改一个颜色，顶部四向围栏改前后围栏；折角做烽火台；摧毁后两侧用箭塔废墟、中间变石路、加石块碎片。**
> **我的结论：可行，方案我认同**，而且复用已验收资产能省一次生图→3D 全链。下面是实施路线 + 我发现的两个缺口。

## 一、为什么可行（复用账）

| 需要的东西 | 现成资产 | 复用方式 |
|---|---|---|
| 城墙主体 | **箭塔**（已验收 3D） | 沿墙线等距重复拼接 |
| 折角塔 | 箭塔 + 新顶饰 | 加"烽火盆"顶饰（碗+火焰粒子） |
| 摧毁态两侧 | **箭塔废墟**（已验收） | 直接替换该段塔 |
| 破口地面 | **主城石路**（本次已定：墙内外到 40 米全是石路） | 零额外美术——破口天然露出石路 |
| 破口碎石 | 新增 decal ×2-3 变体 | 散落石块的透明贴图 decal |

只有两件是新的：**城墙段模型**（或墙身）与**碎石 decal**，加一个**城墙材质**。

## 二、实施路线

1. **城墙段（重复件）**：两条路，我建议 (i)
   - (i) **按新提示词生成"城墙段"**：顶部只有前后两侧围栏（左右留齐平接缝面便于无缝拼接），材质走独立"城墙材质"。一次生成就能把拼接接口做对，且过生图→3D 门有据可依。
   - (ii) 在 Blender 里删掉箭塔的左右围栏段 → 省一次生成，但引入 Blender 工序。
   - 拼接参数：**塔间距 = 塔宽（无缝或极窄缝）**，墙身高度略低于塔顶，形成"墙身 + 塔柱"的节奏。
2. **城墙配色**：独立材质，比建筑更冷更灰的石色；建议在墙顶/墙根加一条极窄的暖色边缘线（金/铜），把"主城墙"和普通建筑区分开——卡通语境下这条边线是廉价且有效的档次感来源。
3. **折角烽火台**：放在三段墙的交接处（每侧 2 处），塔身沿用箭塔、顶部加烽火盆；**烽火只在"有敌来袭"时点燃**（可选，纯表现，能当预警信号用，制作人可要可不要）。
4. **摧毁态（三段独立）**：
   - 两侧塔 → **箭塔废墟**替换（现成换装路径，与建筑废墟同一套代码）。
   - 中间 → 清空墙体，露出**石路**（已在主城石路范围内，不需要额外铺）。
   - 破口两端**保留半截残墙**（不要齐平切掉），加 **2-3 块碎石 decal**。
5. **状态驱动**：Sim 给出该段城墙 HP 状态（完好/摧毁）→ EntityView 换模型 + 贴 decal。现有建筑废墟切换就是这个模式，可直接照搬。

## 三、我发现的两个缺口（需要制作人/GLM 定）

1. **完好城墙没有门，自家兵怎么过？**
   规则是"完好时只有自家士兵可以通过"。如果视觉上是一堵实心墙，自家兵穿墙而过会**看起来像 bug**。
   → 建议：**每道墙留一个门洞（自家通过）**，破口是摧毁后的第二条通道；或者自家通过时做一个"开门"动画/门扇。**这个要请制作人拍板。**

2. **破口宽度必须与 GLM 的通行判定一致。**
   视觉破口多宽、Sim 判定多宽，两边要对同一个数字，否则会出现"看着能过、实际过不去"或反过来的穿越感。
   → 建议定一个值（例如破口 = 车道宽 14 米），我在规格里同步。

## 四、风险

- **接缝**：塔间距与塔宽不匹配会露缝 → 生成时就要求"两端齐平可拼接"。
- **比例**：箭塔偏高细，直接当城墙柱可能显得"一堵栅栏"；必要时把塔按 0.7-0.8 缩放或生成一版矮化的墙用塔。
- **性能**：三段墙 × 每段 N 个塔 = 数十个实例；建议用 GPU instancing 或合并网格（现有建筑量大，注意 draw call）。
