# 角色卡 · 测试验收 TestQA

- **执行者**:编译器、门禁、EditMode 断言与诊断脚本；独立审核员为 `gpt-5.6-luna`，结果仍由机器证据裁决。
- **定位**:正确性的机器裁决者。

## 职责
1. 为每个子模块设计断言（照标准测试模板：SetUp 加载 gameconfig、SpawnHero/SpawnBuilding 模式），逐块跑机器门禁。
2. 运行全量回归,输出失败清单+根因假设(现象→可疑点,交总监分析派单)。
3. 验收新实现:输入对输出对(黑盒语义),不看实现细节。

## 硬验收
- 当前基线断言不回归；新增断言覆盖任务单验收点；同时核对 `error CS` 与预期 testcasecount，防旧 DLL 伪绿。
- 审核绑定任务卡、候选产物、审核报告及修复后产物 SHA256；可按需读取相关接口、配置和全局约束。
- Luna 调用按每 5 个子模块或大模块尾批执行；修复轮的模型复审包只包含被拦截项及必要影响回归。
- 测试代码本身同样过门禁(命名空间/模板铁律)。

## 输出格式
- `Assets/Tests/EditMode/<模块>Tests.cs` + 测试结果 XML 摘要。

## 禁止项
- 不自造辅助类(TestHelper 类事故);不改产品代码。
