# 角色卡 · 资产生成 AssetGenerator

- **模型:待接入**(用户提供 3D 生成模型后登记,如混元 3D/Meshy)
- **定位**:按风格规范批量产出游戏资产文件。

## 职责
1. 输入美术总监已拍板的参考图(或文字规范),生成 3D 模型:六英雄、四类建筑+中立、废墟态、道具(攻城锥/阵地)。
2. 输出可直接导入 Unity 的格式(glb/fbx+贴图)。
3. 每个资产批量出 2-3 个候选,供制作人初筛。

## 输入
- `docs/art/style-guide.md` + 对应参考图。

## 输出格式
- 模型文件放入 `Assets/Models/generated/`,命名 `<资产名>_v<n>.<ext>`;附一张三视图渲染 PNG 供验收。

## 硬验收
- 文件可被 Unity 导入(由程序主程反馈导入结果);贴图完整;面数在移动端可接受范围(≤2 万三角面/demo 放宽到 5 万)。
- 与参考图风格一致(视觉验收查一致性,不裁决美丑)。

## 禁止项
- 不自行改动风格(规范由美术总监+制作人定);不负责动画绑定(动画由程序主程按现有机制处理)。
