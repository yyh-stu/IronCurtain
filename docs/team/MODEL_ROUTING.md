# 模型路由与升级规则

> v4 · 2026-09-10 制作人拍板。**总编排+异构审查=`DeepSeek(V4.1 Flash, API 名 deepseek-flash)`；执行编排/模块负责人/代码执行=`GLM 5.3` 全包。** 模型事实状态以 `../PROJECT_BRIEF.md` 为准。

## 1. 总顺序

1. `rg`、Git、哈希、编译器、测试、像素统计等本地证据优先。
2. `GLM 5.3`(套餐制)承担全部产品代码:Sim/View/测试/工具脚本/文档,量大管饱。
3. `DeepSeek(V4.1 Flash)`总编排:项目级拆解、大模块卡、跨文档冲突、公共契约授权、最终技术裁决。
4. `DeepSeek`异构审查:代码由 GLM 写,审查由 DeepSeek 做,异构成立;固定每 3 个子模块一批,公共接口改动逐个审。
5. 制作人:产品方向、审美、手感、成本与商业的终审;在场即可第 0 级裁决。

## 3. 自审隔离三闸(2026-09-10 新增,因 DeepSeek 一身两岗)

1. **审查独立会话**:审查调用不得与编排共享上下文;**总编排的结论、判断、倾向一律不得进入审查包**。审查包只含任务卡、候选产物、日志、哈希和最小充分依赖。
2. **大模块级反向异构**:大模块收口时由 `GLM 5.3` 复核 DeepSeek 的编排结论(拆分是否合理、验收标准是否可测、边界是否漏项),复核意见随收口报告归档。
3. **制作人终审不变**:任何裁决争议提交制作人。

## 4. DeepSeek 时段与成本

- 2026-09-10 制作人**解除时段禁令**:DeepSeek 全时段可用(此前 `[12:00,18:00)` 禁用作废)。
- 其他高价按量调用(生图/3D/动作/音乐)仍守 **14:00-18:00 峰值禁令**。
- 用得起高频:审核批次由 5 收紧为 3;编排可每窗口冷启动跑一次状态审读。
- 仍禁止:无收益调用、重复读取、为省 token 降低证据完整性。

## 5. 降级链

| 情形 | 处置 |
|---|---|
| DeepSeek 限流/故障 | GLM 5.3 代总编排(它有最完整项目上下文);报告中标注「**同厂非异构审查**」降权 |

## 6. 视觉按执行端路由

| 执行端 | 默认视觉 | 状态 | 权限 |
|---|---|---|---|
| ZCode | 内置 4.5V | 套餐内,实战准确度已验证 | ZCode 端默认视觉验收 |
| 补充/交叉 | **DeepSeek V4.1 多模态** | 2026-09-10 实测可读截图(原生多模态) | 批量预检、交叉验证;不得单独放行 |
| 程序化 | 像素统计、坐标/尺寸测量、日志断言 | 硬证据 | 优先于任何视觉模型 |

放行顺序不变:**程序化测量 > 制作人肉眼 > 视觉模型**。
