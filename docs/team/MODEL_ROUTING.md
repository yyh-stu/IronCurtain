## 3. 自审隔离三闸(2026-09-10 新增,因 DeepSeek 一身两岗)

1. **审查独立会话**:审查调用不得与编排共享上下文;**总编排的结论、判断、倾向一律不得进入审查包**。审查包只含任务卡、候选产物、日志、哈希和最小充分依赖。
2. **大模块级反向异构**:大模块收口时由 `GLM 5.3` 复核 DeepSeek 的编排结论(拆分是否合理、验收标准是否可测、边界是否漏项),复核意见随收口报告归档。
3. **制作人终审不变**:任何裁决争议提交制作人。

## 3.1 边看边改权限（2026-09-10 制作人授权）

- **定义**:允许"看画面→改→再看"闭环,直接落地**表现层**改动(材质/光照/后处理/相机/UI 皮肤/特效/动画表现/坐标比例),无需每次走完整任务卡链路。
- **硬边界**:Sim 逻辑、状态机、公共接口、数值平衡、存档迁移等高风险改动仍走"GLM 生产 + 独立审查"。
- **证据义务**:每次留改前/改后对照(截图 + ≥1 项量化指标)并登记台账。
- **审查**:美术总监亲自改动由**本人之外的模型复核**(标注是否异构)或制作人抽检,不得自我放行;美术结论不得进入异构审查包。
- **授权范围**:仅多模态且被明确授权的模型(当前=`DeepSeek V4.1 Flash`)。**Unity 实机 bug 的定位与修复由该岗位全权负责**。

## 4. DeepSeek 时段与成本

- 2026-09-10 制作人**解除时段禁令**:DeepSeek 全时段可用(此前 `[12:00,18:00)` 禁用作废)。
- 其他高价按量调用(生图/3D/动作/音乐)仍守 **14:00-18:00 峰值禁令**。
- 用得起高频:审核批次由 5 收紧为 3;编排可每窗口冷启动跑一次状态审读。
- 仍禁止:无收益调用、重复读取、为省 token 降低证据完整性。
