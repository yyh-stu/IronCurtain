```text

验收层：机器证据 + Luna 隔离审核 + 分端视觉验收
```

## 一句话职责

- 制作人：决定做什么、是否好看/好玩、是否值得花钱。
- Sol 总编排：把目标变成大模块，授权公共契约，解决跨文档冲突并做最终技术裁决。
- Terra 执行编排：拆分、实现或派发子模块并完成工程验收；核心状态机与公共接口不得下放 Flash。
- Luna Reviewer：隔离分批审核并绑定任务/产物/修复后哈希；普通轮次不做最终放行，同批三轮拦截后由高一级模型裁决。
- TestQA：用编译、断言、哈希、日志和长线冒烟回答“是否满足契约”。
- VisualQA：找画面风险并标注不确定性；精确数值让给程序化测量。
- 资产生成：只在两道人工作流门内生产可导入资产。

## 接入/升级一个模型的准入证据

1. 平台、模型 ID、官方端点与本地 key 位置（不在文档写明文 key）。
2. 配置成功记录。
3. 真实代表性请求和完整响应/产物记录。
4. 与岗位相符的能力标定及失败样本。
5. 费用/额度与升级、停用条件。
6. 制作人或主编排授予的岗位范围。

同 key、同厂商或同端点不能替代第 3–4 项。3D 单次约 ¥5，当前明确不为准入测试单独消耗。
