# 《铁幕:前线》伤害叠算公式(用户拍板 2026-09-04,D28)

> 用途:数值体系权威公式。后续重构 GDD 时,第七章 7.1 统一伤害计算公式以此为准。

## 公式总纲

```
最终伤害 =  攻击力 × 护甲系数 × 克制系数 × 特殊修正系数     ── ① 基础层(GDD 7.1 原样)
          × ( 1 + Σ输出增幅 )                                ── ② 攻击方输出层,同层加算
          × ( 1 + Σ承伤增幅 )                                ── ③ 承伤方承伤层,同层加算
          × ∏( 1 − 免伤ᵢ )                                  ── ④ 承伤方免伤层,逐项乘算
          + 附加伤害                                          ── ⑤ 独立附加项
```

**核心原则:增益类加算(有界不膨胀),免伤类乘算(永不无敌)。**

## 各层归位表

| 层 | 内容 | 数值 |
|---|---|---|
| ① 基础层 | 护甲:镇岳 ×0.8(坠日攻击镇岳重置 ×1.0) | GDD 7.1 |
| ① 基础层 | 克制:镇岳→磐石 ×2.5;逐风冲锋(任意目标)×2.0 | GDD 7.1 |
| ① 基础层 | 修正:磐石盾非破防 ×0.7(星落打盾 ×0.5);镇岳受远程 ×0.7;逐风受远程 ×1.25 | GDD 7.1 |
| ② 输出增幅(加算) | 重伤 −0.15;溃逃 −0.30;海克斯增益(以逸待劳 +0.10 等);沙包(攻击方)−0.50 | 有界线性 |
| ③ 承伤增幅(加算) | 脆弱 +0.10;重伤 +0.15;溃逃 +0.30 | 有界线性 |
| ④ 免伤(乘算) | 沙包 0.50;钢铁洪流开战 3 秒 0.50 → 同挂 = 承 25%(总免伤 75%) | 永不无敌 |
| ⑤ 附加项 | 星落升级·诛灭:+0.01 × 目标最大生命 | 层后加法 |

## 设计依据
- 增益加算:防复利膨胀(两个 50% 增伤乘算 = +125%,加算 = +100%)。
- 免伤乘算:防无敌(免伤叠再多,承伤只逼近 0 不到 0)。
- 与 GDD "海克斯单张生效避免数值崩坏"同哲学:数值永远有界。

## 算例
升级星落攻击"重伤+脆弱"镇岳(满血 200):
基础 = 6 × 0.8 × 0.7 = 3.36 → ×(1+0) → ×(1+0.15+0.10)=×1.25 → ×(1−0) → +0.01×200=+2.0
**最终 = 3.36 × 1.25 + 2.0 = 6.2**

## 实现映射(Sim 层)
- `StatusEffects.AttackBonus`(加数,重伤 −0.15)
- `StatusEffects.DamageTakenBonus`(加数,重伤 +0.15 / 脆弱 +0.10)
- `StatusEffects.DamageReduction`(乘数积,海克斯免伤)
- 溃逃(Routing 状态)在 ApplyAttack 内并入两层:输出 −0.3 / 承伤 +0.3
