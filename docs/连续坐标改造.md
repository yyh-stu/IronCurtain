# 单线地图规格重构 + 连续坐标移动(用户拍板 2026-09-04,优先于 GDD)

> 触发:用户验收 M6.0 截图后指出:(1) GDD 2.2「三排三十格」是**两座相邻建筑之间的每段线空间**,此前实现误把整线做成 3×30;(2) 单位应**连续坐标自由移动**(红警式),不锁格列;(3) 线宽扩大一倍;(4) 建筑视觉远大于一格(逻辑仍单格)。
> 四个方向用户已拍板:连续坐标真自由移动 / 建筑视觉放大逻辑单格 / 程序化自建网格美术 / 渲染管线升 URP。

## 1. 地图尺寸
- 线宽:**6 行**(3 翻倍),Row 0..5。
- 线长:**255 列**(Col 0..254):9 座建筑,相邻建筑中心距 31 格 = 间隔 30 格(对齐 GDD「三排三十格」线空间)。
- 建筑布局(逻辑单格,全部 Row=3;D8 序列):
  | 建筑 | 蓝 Base | 蓝兵营 | 蓝资源点 | 蓝箭塔 | 中立资源点 | 红箭塔 | 红资源点 | 红兵营 | 红 Base |
  |---|---|---|---|---|---|---|---|---|---|
  | Col | 3 | 34 | 65 | 96 | 127 | 158 | 189 | 220 | 251 |
- 集结点:Blue (3,250)、Red (3,4)。

## 2. 连续坐标(Sim 权威)
- 新值类型 `SimVec2{X,Y}`(米)。**1 格 = 1 米**,全部既有数值(移速/射程/视野/溅射)单位从「格」改为「米」,数值不动。
- 格 (row,col) 中心 = `SimVec2(col+0.5, row+0.5)`。
- `Entity.PosF`(SimVec2):单位的连续位置;建筑仍用 `Pos`(格)。单位 `Pos` 格与 `PosF` 同步(向下取整)。
- 单位移动:直线朝目标格中心,速度 = MoveSpeed × 状态/海克斯/冲锋/镇岳衰减;每 tick 直接 `PosF += dir*speed*dt`;到达容差 0.15m。
- **建筑碰撞**:单位被建筑碰撞圆推出(碰撞半径:Base 3.2 / Barracks 2.4 / Tower 2.2 / ResourcePoint 1.6 / 堡垒 1.6 米)。
- **单位软碰撞**:两两距离 < 0.9m 时沿连线对半推开(不占格、无排队)。
- 索敌/攻击/溅射/视野/出击/拒马全部改**欧氏距离(米)**;近战攻击判定 `d ≤ Range + 0.3`;拆塔近战距离 = 建筑碰撞半径 + 0.4。
- 城门点 = 建筑中心 + 朝敌方向 × (碰撞半径 + 0.6) 米(取格);驻军撤出/出击到城门点。
- 单位不再参与 `_occupied` 格占用(只建筑占格);`FreeCell` 语义保留给驻军。
