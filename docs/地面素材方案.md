# 地面素材方案（美术总监提案，2026-09-11）

> 前提：制作人确认当前「灰白棋盘地面」不是最终版，计划走美术管线生成几套地面铺满。
> 本文件是执行方案 + 需要拍板的点。技术前提由我这边核实过（ART-P0 R3 期间）。

## 一、现状（为什么现在长这样）

- 地形是 **286×30 格、每格 1 米**的棋盘；每格是一个 1×0.1×1 的盒子，只用 **3 种纯色材质**（石浅 `#86888d`／石深 `#787a7e`／草 `#5f8149`），靠哈希散点选色。所以看到的是"灰白棋盘 + 15% 绿色散点"，不是贴图。
- 可玩区之外由一块 **void 底板**（`#0a0c12`）填充，硬边方块；迷雾用的色号（16,20,33）和它几乎一样 → 两者在画面上连成一整片黑（这就是"地图边缘那块黑"的真身，不是单纯迷雾）。
- 相机：透视 FOV 30，默认视野宽 **57.2 米**；1080p 下约 **34 像素/米**。

## 二、分辨率结论（决定生成图开多大）

34 px/米意味着 **1 米格子在屏幕上只有 34 像素**，逐格贴 512² 是纯浪费。建议按 **4 米模块（4×4 格）**铺：
1080p 下一个模块约 136 像素 → 单张 **1024² 贴图 ≈ 7.5 倍超采样**，近景特写也够用。

**结论：生成 1024² 无缝贴图，代码按 4m 模块铺 + 多做几个变体轮换。**

## 三、要生成的素材（建议 1 套 8 张 + 变体）

1. 草地（主） 2. 草地（枯黄/深绿变体） 3. 泥土 / 土路 4. 碎石砾石
5. 石板铺装 6. 水岸沙滩过渡 7. 水底 8. 岩壁 / 悬崖（**用来给地图收边，替掉现在那块硬边 void**）

- 尺寸 1024²，**必须无缝（tileable）**。提示词里固定写死：`seamless tileable texture, 四边可拼接, 俯视正交视角, 均匀漫射光, 无阴影无高光无投影, 无边框无留白`。
- 可选再加 2–3 张"点缀"图（草丛簇 / 小石子 / 路面斑驳）当 decal，破大面积重复感。
- 生成提示词与验收口径我出；按桌面《待审核图片》的规矩，成品先放进 `05_建筑样式` 同级的新文件夹给你过。

## 四、代码怎么铺（两个方案，建议 B）

**A. 最小改动（约 1 小时）**：保留逐格盒子，只把 3 个纯色材质换成 6–8 张无缝贴图，按同样的哈希规则分配 + 行列 UV 偏移打散接缝。
→ 画面立刻从"纯色棋盘"变成"有材质的地面"，但格子感还在。

**B. 推荐（半天的活）**：按 **4 米模块合并大网格**（16 格的面合成 1 个 quad），由一张规则化的"地表类型图"决定每个模块用哪张图 + 3–4 个变体轮换，模块交界加过渡 decal。
→ 能把现在的"像素棋盘"变成连续地表；顺势用岩壁/水岸图给地图收边，替掉硬边 void。

两个方案都**只动表现层**（`TerrainView`／`BoardView`／材质），Sim 侧的 `TerrainMap` 一行不改。

## 五、需要你定四件事

1. **风格锚**：草地绿主色（最稳，地图本来就有河+岛）？还是苔原／沙地／雪地？
2. **是否接受"从棋盘格变连续地表"**：观感变化较大，但更像成品；不接受就走方案 A。
3. **生成时段**：建议避开 14:00–18:00 计费峰值；一套 8 张 + 2–3 变体 ≈ 10–11 张图。
4. **格子感要不要留**：如果"格子"本身是你想要的风格，就只换贴图（方案 A），不要做模块合并。
