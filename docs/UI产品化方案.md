# UI 产品化方案（制作人待拍板,2026-09-10）

> 现状:面板/血条/顶栏全部是 Unity IMGUI(GUI.Box/默认字体)——win95 灰框味,与产品级 3D 美术严重不配(制作人原话"一股 demo 味")。本文件给三条路线+推荐。

## 问题清单(全部 IMGUI 天生限制)

- 面板=灰盒子+默认字体,无圆角/描边/底纹/动效
- 血条=纯色矩形,无渐变/边框质感
- 无过渡动画(面板开合瞬开瞬关)、无音效联动、无 hover 反馈
- 文字=动态字体默认渲染,小字号发虚

## 路线对比

| | A. IMGUI 换肤 | B. uGUI+免费皮肤包(推荐) | C. uGUI+AI 定制皮肤 |
|---|---|---|---|
| 做法 | 自定义 GUISkin(贴图框体+字体) | Canvas+九宫格贴图(Kenney UI 包等 CC0)+TextMeshPro | AI 生图(P图 UI 皮肤→九宫格切图) |
| 观感上限 | 中(治标) | **高(专业游戏观感)** | 最高(风格完全定制,匹配卡通画风) |
| 工程量 | 1-2 天 | 3-5 天(面板/顶栏/结算/血条全部迁移 uGUI) | B 基础上+皮肤制作 1-2 天 |
| 成本 | ¥0 | ¥0(Kenney UI 系 CC0) | 生成费用 ¥10-30 |
| 风险 | 低,但天花板明显 | 血条是世界空间(需 WorldSpace Canvas 或保留 mesh+贴图化),迁移量大 | AI UI 皮肤九宫格切割成功率待验 |

## 推荐执行(分两步,先快后好)

**第一步(半天,立即去 demo 味)**:不动框架,先做三件立竿见影的——
1. uGUI 之前先换**动态字体→TextMeshPro 风格字体贴图**不可行(IMGUI)→ 改用**高质量中文字体**(思源黑体/站酷,免费商用)替换默认字体,字号加大加描边
2. 面板背景贴图化:GUI.Box 换 GUI.DrawTexture(深色半透明圆角贴图一张,可 AI 生成或 PS 十分钟)——一张贴图全局生效
3. 主色调统一:按钮/面板/血条统一游戏主题色(钢蓝+琥珀),去默认灰

**第二步(3-5 天,产品级)**:路线 B 全面迁移 uGUI——
- Canvas 分层:主 HUD(顶栏 EP/计时)+操作面板(升级/海克斯/道具)+世界空间(血条/偏好标签)
- TextMeshPro 中文 SDF 字体(清晰不糊)
- Kenney UI Pack(CC0,含九宫格框/按钮三态/图标)起步,后续可换 AI 定制皮肤
- 过渡动画:面板开合 0.15s 缩放淡入(DOTween 或自带)
- 血条:世界空间 Canvas 或保留现 mesh 换 SLICED 贴图(渐变+边框)
